# C5 — X7, part 1: measure events that come without a window

Model: haiku · Effort: low · Worktree: yes, `WT = ~/Developer/g-cqd/VMRunner-chains/c-app` (branch `chain/c-app`) · Chain: C, card 5 of 6 (after C4; next C6)

Cause, from the code: `InputLatencyMonitor.observe(_ event: NSEvent)` (its guard, line 108) drops any event whose `event.window` is nil. An event posted to the process with `CGEventPostToPid` carries no window number, so AppKit gives pointer events none. Key events are attributed to the key window by AppKit, which is why keys were counted and pointers stayed at `n=0` (roadmap 0037, "What the monitor missed").

     /// the process (`CGEventPostToPid`) carries no window number, so AppKit gives a pointer event none; without this, such

     static func measuredWindow(of event: NSEvent, keyWindow: NSWindow?) -> NSWindow? {

     }
