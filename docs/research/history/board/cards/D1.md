# D1 — Never restore windows from saved application state: the app always opens a window at launch

Model: haiku · Effort: low · Worktree: yes, `WT = ~/Developer/g-cqd/VMRunner-chains/fix-launch` (branch `chain/fix-launch`, from main e71c874) · Chain: D, card 1 of 1

Why: a real run showed that a stale entry in the OS-side restoration store for the app's bundle id made every launch open NO window (log: `shouldRestoreState=1 hasPersistentStateToRestore=1`, then no window; `--start` never ran). `-ApplePersistenceIgnoreState YES` opened the window. The app has no documents to restore (window frames use their own autosave), so it never restores. The default is REGISTERED (held in memory, never written to disk).

- **Change:**
  1. In `enum PreferencesDomain`, after `isSeparate`, add:
     ```swift
     /// Registers (never writes) the defaults every launch needs. `ApplePersistenceIgnoreState` makes AppKit neither restore windows
     /// from saved application state nor save it: the app has no documents to restore, and a stale entry in the system's
     /// restoration store once made every launch open no window at all.
     static func registerLaunchDefaults(on defaults: UserDefaults = .standard) {
         defaults.register(defaults: [launchKey: true])
     }

     /// The AppKit key `registerLaunchDefaults` registers.
     static let launchKey = "ApplePersistenceIgnoreState"
     ```
  2. In `VMRunnerApp.init`, directly after `AppPaths.refuseUnusableOverride()`, add `PreferencesDomain.registerLaunchDefaults()`.
  3. Append to `PreferencesDomainTests.swift` (inside the existing file, a new struct):
     ```swift
     struct LaunchDefaultsTests {
         @Test func theLaunchDefaultIsRegisteredInMemoryAndNeverWritten() throws {
             let name = "LaunchDefaultsTests-\(UUID().uuidString)"
             let suite = try #require(UserDefaults(suiteName: name))
             defer { UserDefaults.standard.removePersistentDomain(forName: name) }
             #expect(suite.object(forKey: PreferencesDomain.launchKey) == nil)
             PreferencesDomain.registerLaunchDefaults(on: suite)
             #expect(suite.bool(forKey: PreferencesDomain.launchKey))
             #expect(suite.persistentDomain(forName: name)?[PreferencesDomain.launchKey] == nil, "registered, not written")
         }
     }
     ```
