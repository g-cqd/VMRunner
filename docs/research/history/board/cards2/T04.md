## Why

The two runner follow-ups of the real-guest run:

**(a) `scanout.png.partial` was created with the process's umask mode and then `chmod`-ed to 0600** (ImageIO made the file), so there was a window in which it was readable by others. The picture is now encoded to memory (`CGImageDestinationCreateWithData`) and written by `PrivateFile.replace`: `open` with `O_CREAT | O_EXCL | O_NOFOLLOW | O_CLOEXEC` and mode `0o600` (so the mode is the creation mode, whatever the umask), a leftover temporary removed first and a planted link never followed, then `rename` over the last picture. The one `unsafe` is on the expression of each C call, with the reason in a comment. The temporary file still has the same name, so nothing else changes.

**(b) A SIGTERM ended the runner without writing `commands.log` or the last picture.** `ShutdownSignals` ignores SIGTERM and SIGINT and receives them through `DispatchSource.makeSignalSource(signal:queue: .main)` (the word `DispatchQueue` is banned by SwiftLint; `.main` is fine); the handler runs on the main queue and calls the same path as the time limit: stop the machine, then `finish` writes the picture and `commands.log` and exits. The weak captures: the time limit's task and the signal handler hold the runner weakly.

**Judgement calls (recorded; do not change them):**

1. **The exit status of a run ended by a signal is `128 + signal`** (143 for SIGTERM, 130 for SIGINT), as a shell reports it; the time limit still exits 0. The real-guest run could not record its status, so the owner's script can now tell.
2. **A second request while the machine is stopping ends the run at once** (`finish` without waiting for `machine.stop`): a hung stop cannot trap an owner who presses Ctrl-C twice. The first request logs `<reason>, stopping the machine`; the second `<reason> again, not waiting for the machine`.
3. **`PrivateFile` and `ShutdownSignals` live in the runner executable, not in `VirtioGPURunnerCore`:** ADR-NNNN keeps that target to the command line alone. So `VirtioGPURunnerTests` now depends on the `VirtioGPURunner` executable target and imports it with `@testable import VirtioGPURunner` (SwiftPM supports testing an executable target; the library's own tests are unchanged). Its test target also links the runner's Virtualization and AppKit code; nothing in a test starts anything.
4. **A signal test must use `kill(getpid(), ...)`, not `raise`:** `raise` aims the signal at a thread, which a dispatch signal source does not report (the first version of the test hung until it was killed; it now has `.timeLimit(.minutes(1))` so a hang fails instead of blocking the gate). The test uses `SIGUSR1`, never SIGTERM or SIGINT.
5. **The test of the creation mode sets `umask(0)` for the length of the test.** Process-wide, but this test bundle holds no other test that creates files with the default mode, and the bundle runs in a process of its own.
6. **Not verified (needs a guest; no VM is started by this chain):** that a real run ended by `kill -TERM` writes `commands.log` and the final picture, and exits 143. Read `RunnerMain.stop(because:ended:status:)` hardest.
7. **Found, not fixed (follow-ups):** `commands.log` is still created with `FileManager.createFile(attributes: [.posixPermissions: 0o600])` (the same window as the picture had, if Foundation creates the file before it sets the mode); the PNG encode and write still run on the main queue, once a second, which the non-blocking writer rule frowns on in a hot path.

import Foundation

/// Files only their owner can read, private from the moment they exist. The mode is given to `open`, so there is no moment
/// at which the file has the process's umask mode and no `chmod` after the fact.
enum PrivateFile {
    /// Creates `path`, which must not exist, mode 0600, without following a link at that name. The caller owns the handle.
    static func create(atPath path: String) throws -> FileHandle {
        // `open` gets a NUL-terminated copy of the path that outlives the call; O_EXCL makes it fail when the name exists
        // (a link included) and O_NOFOLLOW when the last component is a link.
        let descriptor = unsafe open(path, O_WRONLY | O_CREAT | O_EXCL | O_NOFOLLOW | O_CLOEXEC, 0o600)
        guard descriptor >= 0 else { throw POSIXError(POSIXError.Code(rawValue: errno) ?? .EIO) }
        return FileHandle(fileDescriptor: descriptor, closeOnDealloc: true)
    }

    /// Puts `data` at `path` as a private file: it is written to `path + ".partial"`, created by ``create(atPath:)`` after
    /// any leftover of that name was removed, and then renamed over `path`, so a reader sees the old file or the new one and
    /// never half of one. The temporary is removed when anything fails.
    static func replace(_ path: String, with data: Data) throws {
        let temporary = path + ".partial"
        try? FileManager.default.removeItem(atPath: temporary)
        let handle = try create(atPath: temporary)
        do {
            try handle.write(contentsOf: data)
            try handle.close()
        } catch {
            try? FileManager.default.removeItem(atPath: temporary)
            throw error
        }
        // Both names are NUL-terminated copies that outlive the call.
        guard unsafe rename(temporary, path) == 0 else {
            let code = POSIXError.Code(rawValue: errno) ?? .EIO
            try? FileManager.default.removeItem(atPath: temporary)
            throw POSIXError(code)
        }
    }
}
````

import Foundation

/// Turns the signals that ask the runner to end into calls on the main queue. No code runs in signal context: each signal is
/// ignored and received through a dispatch source instead (the kernel reports a signal to such a source even when it is
/// ignored), so the handler is ordinary main-queue code that may write files, log and end the run.
@MainActor
final class ShutdownSignals {
    private let signals: [Int32]
    private var sources: [any DispatchSourceSignal] = []

    /// Starts watching `signals`; `handler` runs on the main queue once for each signal that arrives.
    init(signals: [Int32] = [SIGTERM, SIGINT], handler: @escaping @MainActor (Int32) -> Void) {
        self.signals = signals
        for number in signals {
            signal(number, SIG_IGN)
            let source = DispatchSource.makeSignalSource(signal: number, queue: .main)
            source.setEventHandler {
                MainActor.assumeIsolated { handler(number) }
            }
            source.resume()
            sources.append(source)
        }
    }

    /// Stops watching and gives each signal its default action back.
    func stop() {
        for source in sources { source.cancel() }
        sources.removeAll()
        for number in signals { signal(number, SIG_DFL) }
    }
}
````

struct PrivateFileTests {
    /// A new directory under /tmp; the test removes it.
    private static func scratch() throws -> String {
        let directory = "/tmp/vmr-private-file-\(UUID().uuidString)"
        try FileManager.default.createDirectory(
            atPath: directory, withIntermediateDirectories: false, attributes: [.posixPermissions: 0o700])
        return directory
    }

    private static func mode(of path: String) throws -> Int {
        (try FileManager.default.attributesOfItem(atPath: path)[.posixPermissions] as? Int) ?? -1
    }

    @Test
    func aNewFileHasTheOwnerOnlyModeFromItsCreationWhateverTheUmask() throws {
        let directory = try Self.scratch()
        defer { try? FileManager.default.removeItem(atPath: directory) }
        let previous = umask(0)
        defer { _ = umask(previous) }
        let handle = try PrivateFile.create(atPath: directory + "/new")
        try handle.close()
        #expect(try Self.mode(of: directory + "/new") == 0o600, "the mode was given to open, not set afterwards")

@testable import VirtioGPURunner

@MainActor
struct ShutdownSignalsTests {
    @Test(.timeLimit(.minutes(1)))
    func aSignalReachesTheHandlerOnTheMainThreadAndTheProcessSurvives() async {
        var watch: ShutdownSignals?
        let (number, onMainThread) = await withCheckedContinuation { (continuation: CheckedContinuation<(Int32, Bool), Never>) in
            watch = ShutdownSignals(signals: [SIGUSR1]) { continuation.resume(returning: ($0, Thread.isMainThread)) }

            _ = kill(getpid(), SIGUSR1)
        }
        watch?.stop()
        #expect(number == SIGUSR1)
        #expect(onMainThread, "the handler is ordinary main-queue code, not a signal handler")
    }
}
