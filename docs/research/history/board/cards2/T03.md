## Why

Two behaviours go in one commit because both bound what one request costs the main queue, on which the app runs the device. They touch different files and share no code, so they can be read separately.

**(a) Serving an element moves into the library.** The runner's `GPUDevice` did, per queue element: read all of it once (at most `GPULimits.maxCommandBytes`), or only its 24-byte header when it is longer, answer an oversized request as an invalid parameter on the control queue, hand the copy to `GPUDeviceState`, write the answer only when it fits the room the guest left, and give the element back exactly once on every path. The app's adapter (T05) needs the same. `QueueElement` (a protocol: readable and writable byte counts, `read(count:)`, `write(_:)`, `giveBack()`) and `GPUDeviceState.serve(_:on:memory:whenHandled:)` carry those rules; each adapter conforms its framework's element and reads the outcome. The runner's `GPUDevice` now calls it, with the same effects in the same order (`whenHandled` runs after the command was carried out and before the answer is written, which is where the runner recorded the request and showed the picture). The library imports nothing, so bytes are `[UInt8]`; the runner's `FrameworkQueueElement` converts `Data`.

**(b) A transfer's cost follows the backing's pieces.** `transferToHost2D` made, per row, one list of guest-memory pieces (an array) and one copy per piece, and appended every row to a temporary of up to 64 MiB; a hostile resource of 1 × 16 777 216 pixels took 21.9 s in a debug build with an in-memory fake. Now a rectangle as wide as its resource is one span (its rows follow each other in the backing): its pieces are listed once, each is copied once, into one buffer made once; a narrower rectangle is read one span per row. All of it is staged first and written to the resource only when every read succeeded (the no-partial-write guarantee), and the overflow checks (`multipliedReportingOverflow`, `addingReportingOverflow`, `pieces(offset:length:)` returning `nil` past the backing) are unchanged.

**Judgement calls (recorded; do not change them):**

1. **A row cap for the narrower rectangles: `GPULimits.maxTransferRows = 8192`.** A narrower rectangle still costs one copy per row, and rows are not bounded by bytes (a 2 × 8 388 608 resource is 64 MiB). Such a transfer above 8192 rows is refused as an invalid parameter before any read. 8192 is the height of the largest scanout the Linux driver makes (`YRES_MAX` in its `virtgpu_display.c`); a full-width rectangle is not subject to it (one span). I judged a hard per-request byte budget not needed: a request's bytes are already bounded by `maxResourceBytes` (64 MiB, a few tens of milliseconds of copying), and a smaller cap would refuse a legitimate full 4K frame (33 MB) that T05 allows.
2. **The order of two error answers can differ** when a full-width transfer has both an unreadable early piece and a span that ends past the backing: it now answers `errInvalidParameter` (the span is checked first), before it answered by the first failing row. Nothing is written in either case and no test depends on it.
3. **Found, not fixed (follow-up):** the scanout flush (`GPUDeviceState.picture(of:in:)`) still copies the scanout rectangle row by row, an O(rows) loop on the main queue for a resource of 1 × 16 777 216; and the encode of the PNG in the runner's `ScanoutDump` runs on the main queue once a second.

/// One element of a virtio queue as the device sees it: the bytes the guest wrote for the device, the room it left for the
/// answer, and the one way back to the guest. An adapter conforms its framework's element to this protocol, so the rules of
/// serving an element are written once, here, and tested without a machine.
package protocol QueueElement {
    /// The bytes the guest wrote for the device, all buffers together.
    var readableByteCount: Int { get }
    /// The room the guest left for the answer, all buffers together.
    var writableByteCount: Int { get }
    /// Copies the first `count` readable bytes, exactly `count` of them or an error. `serve` reads an element at most once,
    /// because the guest may change its memory between two reads.
    func read(count: Int) throws -> [UInt8]
    /// Writes the answer into the writable buffers. `serve` calls it only when the answer fits `writableByteCount`.
    func write(_ bytes: [UInt8]) throws
    /// Gives the element back to the guest, which is told that it is used. `serve` calls it exactly once.
    func giveBack()
}

/// What became of the answer to one served element.
package enum AnswerStatus {
    case written
    /// The request has no answer: it came on the cursor queue.
    case notNeeded
    /// The guest left less room than the answer needs, so nothing was written.
    case didNotFit(needed: Int, available: Int)
    case failed(any Error)
}

/// What serving one element did, for the adapter's counters and log.
package enum ServeOutcome {
    /// The request was read and carried out.
    case handled(answer: AnswerStatus)
    /// The request was longer than the device reads. Only its header was read; `answer` is the refusal's.
    case oversized(length: Int, answer: AnswerStatus)
    /// The request could not be read.
    case unreadable(length: Int, error: any Error)
}

extension GPUDeviceState {
    /// Serves one queue element, whatever it holds. The request is read once, in one piece, and a request longer than
    /// `GPULimits.maxCommandBytes` only as far as its header, which is answered as an invalid parameter on the control queue.
    /// `whenHandled` sees the carried-out command before its answer is written. The answer is written only when it fits the
    /// room the guest left. The element is given back exactly once on every path, after anything was written.
    package mutating func serve(
        _ element: some QueueElement, on queue: GPUQueueKind, memory: some GuestMemoryReader,
        whenHandled: (HandledCommand) -> Void = { _ in }
    ) -> ServeOutcome {
        defer { element.giveBack() }
        let length = element.readableByteCount
        guard length <= store.limits.maxCommandBytes else {
            return .oversized(length: length, answer: refuse(element, on: queue))
        }
        let bytes: [UInt8]
        do {
            bytes = length == 0 ? [] : try element.read(count: length)
        } catch {
            return .unreadable(length: length, error: error)
        }
        let handled = handle(bytes, queue: queue, memory: memory)
        whenHandled(handled)
        guard let response = handled.response else { return .handled(answer: .notNeeded) }
        return .handled(answer: Self.write(response, to: element))
    }

    /// Reads only the header of an element that is too long, and answers it on the control queue.
    private func refuse(_ element: some QueueElement, on queue: GPUQueueKind) -> AnswerStatus {
        let header = (try? element.read(count: GPUWireSize.header)) ?? []
        guard queue == .control else { return .notNeeded }
        let request = GPUDecoder.decode(header, limits: store.limits)
        return Self.write(GPUResponse.error(.errInvalidParameter).encoded(answering: request.header), to: element)
    }

    private static func write(_ response: [UInt8], to element: some QueueElement) -> AnswerStatus {
        let available = element.writableByteCount
        guard available >= response.count else { return .didNotFit(needed: response.count, available: available) }
        do {
            try element.write(response)
            return .written
        } catch {
            return .failed(error)
        }
    }
}

    /// `declaredLength` is what the guest claims to have written; `payload` is what a read returns first, padded with zeros.
    init(payload: [UInt8] = [], declaredLength: Int? = nil, room: Int = 1 << 20, readFails: Bool = false, writeFails: Bool = false) {

    }

private struct CountingGuestMemory: GuestMemoryReader {
    final class Counter {
        var calls = 0
        var bytes = 0
    }

    let base: FakeGuestMemory
    let counter = Counter()

    func copyBytes(atPhysicalAddress address: UInt64, count: Int) -> [UInt8]? {
        counter.calls += 1
        counter.bytes += count
        return base.copyBytes(atPhysicalAddress: address, count: count)
    }
}

    private static func resource(width: UInt32, height: UInt32, pieces: Int) -> (store: ResourceStore, memory: CountingGuestMemory) {
        var store = ResourceStore(limits: GPULimits())
        var memory = FakeGuestMemory()
        let total = Int(width) * Int(height) * GPUPixelFormat.bytesPerPixel
        var entries: [GPUMemoryEntry] = []
