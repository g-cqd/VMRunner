Why: a suspended machine's memory image is restored into a configuration built anew; the seed drive is part of it. Two
cases, INDEX-L decision 5:

- **An edit adds, removes or moves the spec in use.** The drive appears, disappears or holds another seed.
  `restoresSavedState(of:)` now compares `activeProvisioningSpecPath`, so `VMLibrary.update` drops the saved state at the
  edit, as it does for the disk and the network device.
- **The spec or a script changed outside the app.** The configuration is the same, so the restore would succeed with a
  guest that read the old seed while its drive now holds another. `ProvisioningSeed.prepare` keeps the SHA-256 of the last
  start's seed in the bundle (`ProvisioningSeed.sha256`, 0600; not a run leftover) and drops the saved state when the new
  seed's digest differs, including "a seed now and none then" and the reverse. It runs in `VZMachineFactory.prepare`, before
  `VMController.prepare(run:)` reads `bundle.hasSavedState` for `canRestore`: with the state gone, the existing branch builds
  the cold-start display and prepares again (the second `prepare` finds the digest it just wrote and keeps nothing to drop),
  so the machine boots afresh instead of failing a restore. A saved state from before this change, with no spec, has no
  digest file and none is computed: it is kept.

`SeedImage.bytes(for:)` becomes `package` so the app hashes the very bytes the library writes.

```swift
    /// Builds this start's seed into `bundle` when the machine has a spec in use, and removes the last one otherwise. It runs
    /// before the machine is configured, so the seed is the spec and its scripts as they are now. A saved state is kept only
    /// while the seed is the one it was saved with: the digest of the last start's seed is kept beside it, and a seed added,
    /// changed or removed since drops the saved state, so the machine boots afresh instead of failing its restore.
    static func prepare(for config: VMConfig, bundle: VMBundle) throws {
        bundle.remove(bundle.provisioningSeed)
        var digest: String?
        if let path = config.activeProvisioningSpecPath {
            let seed = try compile(specAt: path, instanceID: config.id.uuidString).seed
            digest = SHA256.hash(data: SeedImage.bytes(for: seed)).map { ($0 < 16 ? "0" : "") + String($0, radix: 16) }.joined()
            try SeedImage.write(seed, to: bundle.provisioningSeed)
        }
        let previous = try? String(contentsOf: bundle.provisioningSeedDigest, encoding: .utf8)
        if bundle.hasSavedState, previous != digest { bundle.discardSavedState() }
        if let digest {
            try Data(digest.utf8).writePrivately(to: bundle.provisioningSeedDigest)
        } else {
            bundle.remove(bundle.provisioningSeedDigest)
        }
    }
```
