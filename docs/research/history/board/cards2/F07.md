# F07 — The host-information folder: refuse one that cannot be emptied, and remove it when the machine stops

Model: haiku · Effort: low · Worktree: yes, `WT = ~/Developer/g-cqd/VMRunner-chains/f-followups` (branch `chain/f-followups`) · Chain: F, card 7 of 12 (after F06; next F08)

Anchors: locate every edit by its text (`grep -nF`), never by a line number. Verified on `main` at `a98fd14`.

Why (read from the code): `VMBundle.freshHostInfoFolder()` calls `remove(hostInfoFolder)`, which logs a failed removal and
goes on, then `AppPaths.createPrivateDirectory`, which accepts a folder that is already there when it is private. So a
copied bundle whose `HostInfo` holds a subfolder the app may not empty (mode 0555 with a file inside) is served to the guest
with its old, possibly forged, files. And nothing removes `HostInfo` after a run: the last battery, network and time-zone
facts stay in the bundle and travel with a duplicate. After this card the folder must be empty once it is made again, or
the start fails with `AppPaths.UnsafeDirectory`; and `discardEphemeral()`, which `VMController.release()` runs at every stop
(and the library runs at launch for every machine that is not running, and `prepareEphemeral` runs before a disposable
start), removes `HostInfo` with the other files of a run. No line is added to the `VMController` class body (INDEX-E: it is
at its `type_body_length` limit): the stop path already calls `discardEphemeral()`.

Order check (read from `VMController`): `prepareEphemeral` (which calls `discardEphemeral`) runs before
`factory.prepare`, which builds the configuration and makes the folder; so the new removal never takes the folder from
under a machine that is starting.

```swift
    /// Removes whatever is at `hostInfoFolder` and makes the folder again, private and empty. Files or a link a copied bundle
    /// left there are gone before a guest can see them.
    /// - Throws: `AppPaths.UnsafeDirectory` when something there could not be removed (a subfolder the app may not empty),
    ///   so it is never served.
    func freshHostInfoFolder() throws -> URL {
        remove(hostInfoFolder)
        try AppPaths.createPrivateDirectory(hostInfoFolder)
        guard try FileManager.default.contentsOfDirectory(atPath: hostInfoFolder.path).isEmpty else {
            throw AppPaths.UnsafeDirectory(path: hostInfoFolder.path, reason: "what was left in it could not be removed")
        }
        return hostInfoFolder
    }
```
