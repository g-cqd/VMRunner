# F09 — Drop a saved memory image when the disk interface, the disk serial or the host-information share changes

Model: haiku · Effort: low · Worktree: yes, `WT = ~/Developer/g-cqd/VMRunner-chains/f-followups` (branch `chain/f-followups`) · Chain: F, card 9 of 12 (after F08; next F10)

Anchors: locate every edit by its text (`grep -nF`), never by a line number. Verified on `main` at `a98fd14`.

Why (read from the code): `VMLibrary.update(_:)` discards a suspended machine's memory image when Secure Boot, the network
mode or a setting that forbids saved state changes, because the image cannot be restored into a different machine. Three
options added since change the device configuration too, and are not checked: the disk's interface (virtio or NVMe), the
virtio disk's serial number, and whether host information is shared at all (an extra virtio-fs device). A restore after
such a change fails and falls back to a cold boot. After this card one function says which changes keep the image,
`VMConfig.restoresSavedState(of:)`, and `update` uses it. Sharing one more or one fewer fact keeps the image: the device is
the same while at least one fact is shared.

The `VMLibrary` class body is near its `type_body_length` limit: this card adds no counted line to it (the condition moves
into a `VMConfig` extension, and the comment lines it replaces are not counted).

## Change

1. `VMConfig.swift`: directly before the line `struct DisplayPreset: Identifiable, Hashable, Sendable {` insert:

```swift
extension VMConfig {
    /// Whether a memory image saved by a machine with the `previous` configuration can be restored into one built from this
    /// one. Secure Boot lives in the firmware's variable store, which the framework cannot compare; the network device (NAT,
    /// none or the user-mode stack), the disk's interface and serial number, and the host-information share (an extra
    /// file-system device while anything is shared) are part of the device configuration a saved state must match.
    func restoresSavedState(of previous: Self) -> Bool {
        secureBoot == previous.secureBoot && networkMode == previous.networkMode && diskInterface == previous.diskInterface
            && diskSerial == previous.diskSerial && hostInfo.isEmpty == previous.hostInfo.isEmpty
    }
}

```

```swift
    @Test func changingTheDiskOrTurningHostInformationOnOrOffDropsSavedState() throws {
        let (library, directory) = try makeLibrary()
        defer { try? FileManager.default.removeItem(at: directory) }
        var config = try addMachine(to: library)
        let bundle = library.bundle(config.id)

        config.diskInterface = .nvme
        library.update(config)
        #expect(!bundle.hasSavedState, "an NVMe disk is another device than a virtio one")

        try Data("memory".utf8).write(to: bundle.savedState)
        config.diskSerial = "VMR0001"
        library.update(config)
        #expect(!bundle.hasSavedState, "the serial number is part of the disk device")

        try Data("memory".utf8).write(to: bundle.savedState)
        config.hostInfo.timeZone = true
        library.update(config)
        #expect(!bundle.hasSavedState, "sharing host information adds a file-system device")

        try Data("memory".utf8).write(to: bundle.savedState)
        config.hostInfo.battery = true
        library.update(config)
        #expect(bundle.hasSavedState, "sharing one more fact keeps the same device")
    }

```
