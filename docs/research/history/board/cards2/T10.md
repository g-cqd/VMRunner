## Why

T09 puts the custom GPU in a machine and keeps the newest picture; this card shows it. A machine on the custom GPU gets its own window, shown in place of the framework's view.

**Which screen.** The machine's model offers `customDisplay`, the running guest's custom GPU or `nil`; `MachineView` shows the new `CustomGPUDisplay` (an `NSViewRepresentable`) when it is there and `VMDisplay` as before when it is not. The phase is not touched: a machine on the custom GPU still has a `VZVirtualMachine`, so `.running(machine, settings)` stays the phase of every running machine and only the view chooses what to draw. (This choice does not depend on how `MachineModel.Phase` is written, which another piece of work changes.)

**The view.** `CustomGPUView` is a layer-backed `NSView`: the layer's contents are the newest picture as a `CGImage`, `contentsGravity = .resizeAspect`, a black background, and a sublayer for the guest's cursor placed by the guest's position and hot spot (`ScreenPlacement`, pure: the picture is shown at the largest size that fits the view with its aspect ratio, centered, one guest pixel as large as one pixel of the picture; the cursor is hidden while it has no picture). The view accepts the first responder and takes the keyboard when it first moves into a window, like the framework's view; it **swallows `keyDown`** so that a key press does not beep: the guest has no keyboard or pointer path through this view yet (a later card adds it). Clipboard sharing is unchanged (the spice agent port is on its own virtio console device).

**One picture per refresh.** `CustomScreen` hands its presenter (the view) at most one picture per 16 ms: the first at once, the ones that follow within the interval as the newest of them when the interval has passed. It uses the library's `FrameThrottle` and at most one timer task (`self` weak), and no timer while nothing waits or no view is attached. A guest that flushed 640 times a second in the real run therefore costs the app one image per refresh. The screen keeps the newest picture for a view that comes later: **full screen swaps the view for a new one**, which attaches to the same screen and draws the newest picture at once; the device is not touched, and a late detach of the replaced view does not detach the new one. The cursor is not held back (a move is a layer position).

**Converting a picture.** `ScreenPicture.cgImage` describes the guest's bytes to Core Graphics instead of rewriting them: for each of the library's eight pixel formats the bitmap description says whether the four bytes are read as a little- or big-endian word and whether the padding or alpha byte comes first or last, so the image costs one copy of the bytes into its data provider (about 4 MB at 1280 × 800, 33 MB at 4K) and no pass over the pixels. (The runner's `ScanoutImage.rgbx` rewrites every pixel into a new array; the app does not use it.) A scanout skips the fourth byte; a cursor in a format that has an alpha byte is drawn with it, read as premultiplied. A scratch program built with `-O`, on this Mac, for a 1280 × 800 picture: 0.075 ms for the data copy and the image, against 1.25 ms for the per-pixel loop of `ScanoutImage.rgbx` (about 17 times more), and 0.135 ms for the library's copy of the rows at each flush (300 flushes a second would be about 4 % of a core). A debug build is slower. None of this is measured in the app itself; the cost per second is at most 62 images.

**Shared container.** `DisplayContainer` (the framework's view, pinned to the four edges, the keyboard given once, the container's size reported) becomes a subclass of a new `ScreenContainer` that holds any hosted view; `CustomGPUContainer` is the other subclass. `DisplayContainerTests` pass unchanged. `InputLatencyMonitor.holdsMachineView` also recognises `CustomGPUView` (it is now internal so a test reaches it).

````swift
import CoreGraphics
import Foundation
import VirtioGPU

/// A picture of the guest's display, or of its cursor, as a `CGImage`. The image reads the guest's bytes where they are: the
/// bitmap description says where red, green, blue and the padding or alpha byte sit for each of the library's pixel formats, so
/// making one costs a copy of the bytes into the image's data and no pass over the pixels.
enum ScreenPicture {
    /// How the four bytes of a pixel, in memory order, map to a 32-bit word of color channels.
    private static func bitmapInfo(_ format: GPUPixelFormat, alpha: Bool) -> CGBitmapInfo {
        let order: CGBitmapInfo
        let alphaFirst: Bool
        let hasAlpha: Bool
        switch format {
        case .b8g8r8a8, .b8g8r8x8: (order, alphaFirst, hasAlpha) = (.byteOrder32Little, true, format == .b8g8r8a8)
        case .a8r8g8b8, .x8r8g8b8: (order, alphaFirst, hasAlpha) = (.byteOrder32Big, true, format == .a8r8g8b8)
        case .r8g8b8a8, .r8g8b8x8: (order, alphaFirst, hasAlpha) = (.byteOrder32Big, false, format == .r8g8b8a8)
        case .a8b8g8r8, .x8b8g8r8: (order, alphaFirst, hasAlpha) = (.byteOrder32Little, false, format == .a8b8g8r8)
        }
        let info: CGImageAlphaInfo
        switch (alpha && hasAlpha, alphaFirst) {
        case (true, true): info = .premultipliedFirst
        case (true, false): info = .premultipliedLast
        case (false, true): info = .noneSkipFirst
        case (false, false): info = .noneSkipLast
        }
        return order.union(CGBitmapInfo(rawValue: info.rawValue))
    }

    /// The image of `update` in the sRGB space, or `nil` for an empty picture or one whose bytes are not `width × height × 4`.
    /// A scanout has no meaningful alpha, so its fourth byte is skipped; a cursor (`alpha: true`) in a format that has an alpha
    /// byte is drawn with it, read as premultiplied, which is how the Linux display driver writes a cursor.
    static func cgImage(_ update: ScanoutUpdate, alpha: Bool = false) -> CGImage? {
        let (width, height) = (Int(update.width), Int(update.height))
        let rowBytes = width * GPUPixelFormat.bytesPerPixel
        guard width > 0, height > 0, update.pixels.count == rowBytes * height,
            let space = CGColorSpace(name: CGColorSpace.sRGB), let provider = CGDataProvider(data: Data(update.pixels) as CFData)
        else { return nil }
        let info = bitmapInfo(update.format, alpha: alpha)
        // Unsafe only through the type of `decode`, which is nil here: no pointer is passed.
        return unsafe CGImage(
            width: width, height: height, bitsPerComponent: 8, bitsPerPixel: 32, bytesPerRow: rowBytes, space: space,
            bitmapInfo: info, provider: provider, decode: nil, shouldInterpolate: false, intent: .defaultIntent)
    }
}
````

````swift
import CoreGraphics
import VirtioGPU

/// Where the guest's picture and cursor sit in the view that shows them. The picture is shown at the largest size that fits the
/// view with its aspect ratio, centered; every rectangle here has its origin at the top left of the view.
enum ScreenPlacement {
    /// The rectangle the picture occupies, or `.zero` when either size is empty.
    static func pictureRect(picture: CGSize, in view: CGSize) -> CGRect {
        guard picture.width > 0, picture.height > 0, view.width > 0, view.height > 0 else { return .zero }
        let scale = min(view.width / picture.width, view.height / picture.height)
        let size = CGSize(width: picture.width * scale, height: picture.height * scale)
        return CGRect(x: (view.width - size.width) / 2, y: (view.height - size.height) / 2, width: size.width, height: size.height)
    }

    /// The rectangle of the cursor's image: its hot spot sits on the cursor's position, and one guest pixel is as large as one
    /// pixel of the picture. `.zero` when the cursor has no picture or the display is empty.
    static func cursorRect(_ cursor: CursorState, picture: CGSize, in view: CGSize) -> CGRect {
        let area = pictureRect(picture: picture, in: view)
        guard let image = cursor.picture, area != .zero else { return .zero }
        let scale = area.width / picture.width
        return CGRect(
            x: area.minX + (CGFloat(cursor.x) - CGFloat(cursor.hotX)) * scale,
            y: area.minY + (CGFloat(cursor.y) - CGFloat(cursor.hotY)) * scale,
            width: CGFloat(image.width) * scale, height: CGFloat(image.height) * scale)
    }
}
````

````swift
import AppKit

/// Hosts the view that shows a machine's screen without exposing its intrinsic size, which would otherwise resize the window
/// to the guest framebuffer. The framework's view and the custom GPU's view are hosted the same way: pinned to the four edges,
/// the keyboard given once, the container's size reported.
class ScreenContainer: NSView {
    /// The view that shows the screen, pinned to the container's edges.
    let hosted: NSView
    var onLayout: ((CGSize) -> Void)?
    private var gaveKeyboard = false

    init(hosting content: NSView) {
        hosted = content
        super.init(frame: .zero)
        // The framework's view turns off `translatesAutoresizingMaskIntoConstraints` itself, so an autoresizing mask does
        // nothing for it: inside a container that Auto Layout sizes (SwiftUI's hosting does) the view stayed at the size of
        // its first layout. The picture was then scaled to that oversized view and cropped by the window. Pin the four edges.
        hosted.translatesAutoresizingMaskIntoConstraints = false
        addSubview(hosted)
        NSLayoutConstraint.activate([
            hosted.leadingAnchor.constraint(equalTo: leadingAnchor),
            hosted.trailingAnchor.constraint(equalTo: trailingAnchor),
            hosted.topAnchor.constraint(equalTo: topAnchor),
            hosted.bottomAnchor.constraint(equalTo: bottomAnchor),
        ])
    }

    @available(*, unavailable)
    required init?(coder: NSCoder) { fatalError("ScreenContainer is created in code only") }

    override var intrinsicContentSize: NSSize {
        NSSize(width: NSView.noIntrinsicMetric, height: NSView.noIntrinsicMetric)
    }

    override func layout() {
        super.layout()
        report("layout")
    }

    /// AppKit lays a view out when it decides to; the size is also reported as soon as the frame changes, so a resize that
    /// does not reach `layout()` still reaches the guest.
    override func setFrameSize(_ newSize: NSSize) {
        super.setFrameSize(newSize)
        report("frame")
    }

    override func viewDidChangeBackingProperties() {
        super.viewDidChangeBackingProperties()
        DisplayDiagnostics.note("backing properties changed: \(windowDescription)")
    }

    /// The screen's view takes the keyboard the first time the display is in a window, so typing reaches the guest without a
    /// click first. Only once: a later move must not take the keyboard from wherever the user put it.
    override func viewDidMoveToWindow() {
        super.viewDidMoveToWindow()
        // AppKit declares `window` unowned(unsafe); it is alive for the duration of this callback and not kept.
        guard !gaveKeyboard, let window = unsafe self.window else { return }
        gaveKeyboard = window.makeFirstResponder(hosted)
    }

    private func report(_ cause: String) {
        let containerSize = DisplayDiagnostics.text(bounds.size)
        let viewSize = DisplayDiagnostics.text(hosted.frame.size)
        DisplayDiagnostics.note("\(cause): container \(containerSize) pt, machine view \(viewSize) pt, \(windowDescription)")
        onLayout?(bounds.size)
    }

    private var windowDescription: String {
        // AppKit declares `window` unowned(unsafe); it is alive for the duration of this call and not kept.
        guard let window = unsafe self.window else { return "no window" }
        return "window \(DisplayDiagnostics.text(window.frame.size)) pt, backing scale \(window.backingScaleFactor), "
            + "full screen \(window.styleMask.contains(.fullScreen))"
    }
}
````

````swift
import AppKit
import VirtioGPU

/// Shows the picture the guest draws on a custom GPU, and its cursor. The picture is the contents of the view's layer, scaled to
/// fit with its aspect ratio over black; the cursor is a layer above it, placed where the guest put it. The view takes the
/// keyboard when it is in a window, like the framework's own view does, but passes nothing to the guest: input for such a
/// machine has no path yet, and the view swallows key presses so that the system does not beep at each of them.
@MainActor
final class CustomGPUView: NSView, ScreenPresenter {
    private let cursorLayer = CALayer()
    private weak var screen: CustomScreen?
    /// The size, in guest pixels, of the picture on show; zero before the first one.
    private(set) var pictureSize = CGSize.zero
    private var cursor: CursorState?
    private var cursorGeneration: UInt64?

    override init(frame: NSRect) {
        super.init(frame: frame)
        wantsLayer = true
        layer?.backgroundColor = CGColor(gray: 0, alpha: 1)
        layer?.contentsGravity = .resizeAspect
        cursorLayer.isHidden = true
        layer?.addSublayer(cursorLayer)
    }

    @available(*, unavailable)
    required init?(coder: NSCoder) { fatalError("CustomGPUView is created in code only") }

    override var acceptsFirstResponder: Bool { true }

    override func keyDown(with event: NSEvent) {}

    override func layout() {
        super.layout()
        placeCursor()
    }

    /// Draws `screen`, and no longer the one drawn before.
    func show(_ screen: CustomScreen) {
        guard self.screen !== screen else { return }
        self.screen?.detach(self)
        self.screen = screen
        screen.attach(self)
    }

    /// Stops drawing: the view is going away.
    func detach() {
        screen?.detach(self)
        screen = nil
    }

    func present(frame: ScanoutUpdate) {
        guard let image = ScreenPicture.cgImage(frame) else { return }
        layer?.contents = image
        pictureSize = CGSize(width: Int(frame.width), height: Int(frame.height))
        placeCursor()
    }

    func present(cursor: CursorState?) {
        self.cursor = cursor
        if cursor?.pictureGeneration != cursorGeneration {
            cursorGeneration = cursor?.pictureGeneration
            let image = cursor?.picture.flatMap { ScreenPicture.cgImage($0, alpha: true) }
            CATransaction.begin()
            CATransaction.setDisableActions(true)
            cursorLayer.contents = image
            CATransaction.commit()
        }
        placeCursor()
    }

    /// The layer's origin is its bottom left corner; the placement's is the top left.
    private func placeCursor() {
        CATransaction.begin()
        CATransaction.setDisableActions(true)
        defer { CATransaction.commit() }
        let rect = cursor.map { ScreenPlacement.cursorRect($0, picture: pictureSize, in: bounds.size) } ?? .zero
        guard rect != .zero, cursorLayer.contents != nil else {
            cursorLayer.isHidden = true
            return
        }
        cursorLayer.frame = CGRect(x: rect.minX, y: bounds.height - rect.maxY, width: rect.width, height: rect.height)
        cursorLayer.isHidden = false
    }
}
````

````swift
/// A guest's pixels as an image: every format the device accepts must come out with the colors the guest wrote.
struct ScreenPictureTests {
    /// Two pixels, one colored (10, 20, 30) and one (200, 100, 50), their fourth byte `fourth`, in the byte order of `format`.
    private func picture(_ format: GPUPixelFormat, fourth: UInt8) -> ScanoutUpdate {
        let offsets = ScanoutImage.channelOffsets(format)
        var pixels = [UInt8](repeating: fourth, count: 8)
        for (index, color) in [[10, 20, 30], [200, 100, 50]].enumerated() {
            pixels[index * 4 + offsets.red] = UInt8(color[0])
            pixels[index * 4 + offsets.green] = UInt8(color[1])
            pixels[index * 4 + offsets.blue] = UInt8(color[2])
        }
        return ScanoutUpdate(width: 2, height: 1, format: format, pixels: pixels)
    }

    /// The red, green, blue and alpha bytes of the pixel at `x` when `image` is drawn into an sRGB bitmap with premultiplied alpha
    /// (the image is read by drawing, as the screen does; the bitmap is the framework's, so no pointer is needed).
    private func channels(of image: CGImage, at x: Int) throws -> [Int] {
        let space = try #require(CGColorSpace(name: CGColorSpace.sRGB))
        // Unsafe only through the type of `data`, which is nil here: the framework allocates the bitmap.
        let context = unsafe CGContext(
            data: nil, width: image.width, height: 1, bitsPerComponent: 8, bytesPerRow: 0, space: space,
            bitmapInfo: CGImageAlphaInfo.premultipliedLast.rawValue)
        try #require(context != nil)
        context?.draw(image, in: CGRect(x: 0, y: 0, width: image.width, height: 1))
        let bytes = try #require(context?.makeImage()?.dataProvider?.data as Data?)
        return bytes[(bytes.startIndex + x * 4)..<(bytes.startIndex + x * 4 + 4)].map { Int($0) }
    }

    @Test(arguments: GPUPixelFormat.allCases, [0, 128, 255] as [UInt8])
    func aScanoutKeepsTheGuestsColorsWhateverItsFormatAndFourthByte(format: GPUPixelFormat, fourth: UInt8) throws {
        let image = try #require(ScreenPicture.cgImage(picture(format, fourth: fourth)))
        #expect(image.width == 2 && image.height == 1)
        #expect(try channels(of: image, at: 0) == [10, 20, 30, 255], "\(format), fourth byte \(fourth)")
        #expect(try channels(of: image, at: 1) == [200, 100, 50, 255], "\(format), fourth byte \(fourth)")
    }

    @Test(arguments: [GPUPixelFormat.b8g8r8a8, .a8r8g8b8, .r8g8b8a8, .a8b8g8r8])

        pixels[alphaIndex] = 128

        #expect(abs(cursor[3] - 128) <= 1 && abs(cursor[0] - 64) <= 1 && cursor[1] == 0 && cursor[2] == 0, "\(format): \(cursor)")
        let opaque = try channels(of: try #require(ScreenPicture.cgImage(update)), at: 0)

    func anEmptyPictureOrOneWithTheWrongNumberOfBytesGivesNoImage() {
        struct Case {
            let width: UInt32
            let height: UInt32
            let bytes: Int
        }
        let cases =
````

````swift
    private(set) var cursor: CursorState?

    private weak var presenter: (any ScreenPresenter)?
    private var throttle: FrameThrottle
    private var tick: Task<Void, Never>?
    private let sleep: (Duration) async throws -> Void
    private let now: () -> UInt64
    private let interval: Duration

    init<C: Clock>(displaySize: CGSize, interval: Duration = frameInterval, clock: C) where C.Duration == Duration {
        self.displaySize = displaySize
        self.interval = interval
        throttle = FrameThrottle(intervalMilliseconds: UInt64(max(interval / .milliseconds(1), 1)))
        sleep = { try await clock.sleep(for: $0) }
        let start = clock.now
        now = { UInt64(max(start.duration(to: clock.now) / .milliseconds(1), 0)) }
    }

    convenience init(displaySize: CGSize) {
        self.init(displaySize: displaySize, clock: ContinuousClock())
    }

    isolated deinit {
        tick?.cancel()
    }

    /// Makes `presenter` the one that draws, and gives it the newest picture and the cursor now. A presenter that was attached
    /// before is no longer called.
    func attach(_ presenter: some ScreenPresenter) {
        self.presenter = presenter
        tick?.cancel()
        tick = nil
        throttle = FrameThrottle(intervalMilliseconds: throttle.interval)
        if let frame, let ready = throttle.offer(frame, atMilliseconds: now()) { presenter.present(frame: ready) }
        presenter.present(cursor: cursor)
    }

    /// Ends `presenter`'s drawing, unless another presenter has replaced it.
    func detach(_ presenter: some ScreenPresenter) {
        guard self.presenter === presenter else { return }
        self.presenter = nil
    }

    func show(_ update: ScanoutUpdate) {
        frame = update
        guard let presenter else { return }
        if let ready = throttle.offer(update, atMilliseconds: now()) {
            presenter.present(frame: ready)
        } else {
            scheduleTick()
        }
    }

    func show(_ update: CursorUpdate) {
        cursor = CursorState.after(update, previous: cursor)
        presenter?.present(cursor: cursor)
    }

    /// One wait at most is pending: it ends a full interval after the picture it was started for was kept back, by when the
    /// interval since the last picture shown has passed.
    private func scheduleTick() {
        guard tick == nil else { return }
        tick = Task { [weak self, sleep, interval] in
            try? await sleep(interval)
            guard !Task.isCancelled else { return }
            self?.intervalPassed()
        }
    }

    private func intervalPassed() {
        tick = nil
        if let ready = throttle.tick(atMilliseconds: now()) { presenter?.present(frame: ready) }
    }
````

````
Show the custom GPU's picture and cursor in the machine's window

A machine on the custom GPU now has a window. The running phase says which
screen to show, the framework's own view or the custom one, and the window
switches between them. The custom view lays the guest's newest picture on a
layer scaled to fit over black and draws the guest's cursor above it, placed by
its position and hot spot. It takes the keyboard like the framework's view but
swallows key presses: input has no path yet.

keeps no timer while nothing waits; a guest that flushes hundreds of times a
second costs one image per refresh, not one per flush. The image reads the
guest's bytes where they are, with a bitmap description for each of the eight
pixel formats, so making it costs one copy and no pass over the pixels. Full
screen swaps the view, and the new one draws the same screen from its newest
picture without restarting the device. The two kinds of display share one
container, so they lay out and take the keyboard the same way, and the input
latency monitor counts the new view as a machine's.
````
