## Commands

Run each in the background and wait for it to exit; each takes 10 to 25 minutes. Count it as one build of the build cap.

1. `cd WT && git status --short`: prints nothing.
2. `cd WT && /bin/bash --noprofile --norc -c 'start=$(date +%s); swift run vmr check tsan > /tmp/d02-tsan-1.log 2>&1; echo "exit=$? seconds=$(( $(date +%s) - start ))"'`
3. The same with `/tmp/d02-tsan-2.log`.
4. For each log (`grep -c` prints `0` and exits 1 when nothing matches; that is expected): `grep -n -E "^(PASS|FAIL) " /tmp/d02-tsan-N.log` and `grep -c -E "ThreadSanitizer|SUMMARY: ThreadSanitizer|Abort trap|signal 6|abort\(\)" /tmp/d02-tsan-N.log`.
5. Only for a log whose step 4 count is not `0` or whose step line is `FAIL`: `grep -n -B5 -A40 -m1 -E "ThreadSanitizer|Abort trap|signal 6|abort\(\)" /tmp/d02-tsan-N.log | head -80`.
6. `cd WT && git status --short`: still prints nothing (the step writes only to `.build-tsan`).

Expected, if the abort does not recur: both runs print `exit=0`, step 4 shows `PASS  tsan` and a count of `0` for each.

## Stop conditions

- A run fails or aborts: do not rerun it, do not change any file, do not edit `Scripts/tsan.supp`. Report step 5's output for it
  and keep the log; the integrator decides whether D18 records a finding.
- Step 6 shows a change: report it and stop.

## Report

A two-row table: run, exit status, seconds, the `PASS`/`FAIL` line, the count of step 4; and step 5's output for a failed run.
The integrator copies the verdict into D18 (`<<TSAN>>`) before D18 is dispatched.
