## Why

A `Stepper` with a `LabeledContent` label put its value beside the title and the arrows at the far edge, while pickers and
`LabeledContent` rows end with their value. `ValueStepper` (in `Sources/VMRunner/Views/Editor/ResourceSteppers.swift`) puts the value just
before the arrows and keeps the title as the stepper's accessibility label. It is used for:

- CPU cores and Memory (`CoreAndMemorySteppers`, shared with the New Machine sheet).
- The New Machine Disk stepper.
- Storage disk size.
- Display: pixel density, width and height.
- Security: runtime limit.

The ranges, steps and value texts are byte-identical to before. The first design (`Stepper { Text }` inside `LabeledContent`) drew the
arrows before the value; the committed form is an `HStack` of the value then a labels-hidden `Stepper`, with `.accessibilityValue(text)`.
The value is secondary grey, like the values of `LabeledContent` rows such as "Disk usage". This card also changes the New Machine sheet,
on purpose, for consistency.

```swift
/// A row with a stepper: the title at the leading edge, and the current value just before the arrows at the trailing edge,
/// where a picker or a `LabeledContent` row puts its value. The stepper keeps the title for VoiceOver.
struct ValueStepper: View {
    let title: String
    @Binding var value: Int
    let range: ClosedRange<Int>
    var step = 1
    let text: String

    var body: some View {
        LabeledContent(title) {
            HStack {
                Text(text).monospacedDigit()
                Stepper(title, value: $value, in: range, step: step)
                    .labelsHidden()
                    .accessibilityValue(text)
            }
        }
    }
}
```
