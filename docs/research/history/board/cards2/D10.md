# D10 — F8, part 1: a DNS-over-TCP answer that finds the guest's buffer full resets the session and is counted

Model: haiku · Effort: low · Worktree: yes, `WT = ~/Developer/g-cqd/VMRunner-chains/d-security` (branch `chain/d-security`) · Chain: D, card 10 of 22 (after D09; next D11)

Anchors: locate every edit by its text (`grep -n`), never by a line number. Verified on `main` at `73bceb0`.

Why (read from the code): `UserNetCore.deliver` frames a DNS-over-TCP answer and calls `flow.enqueueLocalResponse`, then drops
its result (`_ = ...`). When the guest stops reading, earlier answers fill the guest-bound ring (`tcpSendBuffer`, 128 KiB by
default) and the next answer is lost without a trace: the guest's resolver waits for its timeout. Chosen behaviour: count it
(`UserNetStats.dnsAnswersLost`, also on the stats line) and reset the session, so the guest's resolver asks again at once.
Because `deliver` can now end the flow while `drainDNSStream` is still reading that flow's inbox (a query answered at once,
such as AAAA), the drain loop stops when the flow is no longer live.

```swift
    @Test func anAnswerThatFindsTheGuestsBufferFullResetsTheSessionAndIsCounted() throws {
        let rig = start { $0.tcpSendBuffer = 16_384 }
        var guest = GuestConnection(rig: rig, to: (Wire.gateway, 53))
        guest.sendSYN()
        guest.sendACK()
        guest.window = 0  // the guest stops reading: answers stay in its buffer
        let name = "4.3.2.1.in-addr.arpa"
        let first = Wire.dnsQuery(id: 1, name: name, type: 12)
        let second = Wire.dnsQuery(id: 2, name: name, type: 12)
        guest.sendData(Wire.be16(first.count) + first + Wire.be16(second.count) + second)
        #expect(rig.host.resolutions.count == 2)
        // 60 PTR records of 143 bytes: about 8.6 KB an answer, so one fits the 16 KiB buffer and two do not.
        let target = DNSWire.encodeName(String(repeating: "a", count: 60) + "." + String(repeating: "b", count: 60) + ".example") ?? []
        let records = (0..<60).map { _ in DNSRecord(name: name, type: 12, ttl: 60, data: target) }
        for request in rig.host.resolutions {
            rig.core.nameResolved(token: request.token, result: DNSLookupResult(responseCode: 0, records: records))
        }
        guest.collect()
        #expect(guest.sawRST, "the session is reset instead of leaving the guest waiting")
        #expect(rig.core.stats.dnsAnswersLost == 1)
    }
```
