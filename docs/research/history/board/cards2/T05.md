## Why

ADR-NNNN puts the app's Virtualization half in `Sources/VMRunner/Engine`. This card adds it, plus what the library must give an adapter that draws a console in a window:

**The adapter (`Sources/VMRunner/Engine/CustomGPU`, four files).**
- `CustomGPUDevice` (`@MainActor`, the framework's two delegates): it holds the library's `GPUDeviceState`, serves each element of a queue notification with `state.serve`, passes the carried-out command to its sinks (`showFrame` for a scanout picture, `showCursor` for a cursor change), forgets the guest's resources on a device reset but keeps the display size the host chose, and logs the first of each trouble (oversized request, unreadable request, answer that did not fit, answer that could not be written) once through `Log.display`, never more, so a guest cannot make the log grow. `requestDisplaySize(width:height:)` sets the size in the state and, when the framework has made the device, calls `device.update(_:)` with the display event set in the configuration space; the next `GET_DISPLAY_INFO` then reports the new size. It returns `false` and changes nothing for a size the library refuses.
- `CustomGPUDevice.makeConfiguration()` (a second file): the `VZCustomVirtioDeviceConfiguration` for `VZVirtualMachineConfiguration.customVirtioDevices`: device ID 16, PCI class 3 subclass 0x80, 2 queues, `VIRTIO_F_VERSION_1` mandatory, the 16-byte configuration space from `GPUConfigSpace` (one scanout, no capability set, no event), `supportsSaveRestore = false`, and a `VZCustomVirtioDeviceDelegateProvider` on the main queue (the provider holds its delegate weakly: whoever builds the machine holds the device).
- `GuestQueueElement` and `GuestMemoryMapping` (`GuestMemoryReader`): the framework's element and guest memory as the library takes them. They are written to differ from the runner's `FrameworkQueueElement` and `MappedGuestMemory` (dolly flags exact clones of 50 tokens or more across `Sources`; it reported nothing).

**The library (`Sources/VirtioGPU`).**
- The display size is the state's (`displayWidth`, `displayHeight`, from `GPULimits` at first) and `setDisplaySize(width:height:)` changes it. **Limits for the app (decided here):** each side 1 to 8192 (`GPULimits.maxDisplaySide`, the Linux driver's own bound) and a picture of that size must fit one resource (`maxResourceBytes`, 64 MiB): 4K (33 MB) and 5K (59 MB) are allowed, 8K (127 MB) is not. The total-bytes limit (256 MiB) and the resource count are unchanged: seven 4K buffers fit. A guest reset keeps the size.

````swift
import Foundation
import VirtioGPU
import Virtualization

/// A queue element of the framework, as the library serves it. Giving it back is the one call that tells the guest the element
/// is used, and the library makes it exactly once.
@available(macOS 27.0, *)
struct GuestQueueElement: QueueElement {
    let element: VZVirtioQueueElement

    var readableByteCount: Int { element.readBuffersAvailableByteCount }
    var writableByteCount: Int { element.writeBuffersAvailableByteCount }

    func read(count: Int) throws -> [UInt8] {
        let data = try element.readBytes(withExactLength: count)
        return Array(data)
    }

    func write(_ bytes: [UInt8]) throws {
        try element.write(Data(bytes))
    }

    func giveBack() {
        element.returnToQueue()
    }
}
````

````swift
import VirtioGPU
import Virtualization

/// Guest RAM through a device's mapping, for the library's transfers. Each read maps the range the library asks for, checks that
/// the framework mapped all of it, and copies it out once: the guest may change its memory at any time, so only the copy is used.
@available(macOS 27.0, *)
struct GuestMemoryMapping: GuestMemoryReader {
    let device: VZCustomVirtioDevice

    func copyBytes(atPhysicalAddress address: UInt64, count: Int) -> [UInt8]? {
        if count <= 0 { return count == 0 ? [] : nil }
        guard let mapping = device.guestMemoryMapping(atPhysicalAddress: address, length: count) else { return nil }
        guard mapping.length >= count else { return nil }
        // The one unsafe read of guest memory: `count` bytes of a mapping that holds at least that many, copied into an array
        // while the mapping object is still alive (it is what holds the host memory the pointer points into).
        return withExtendedLifetime(mapping) {
            unsafe Array(UnsafeBufferPointer(start: mapping.mutableBytes.assumingMemoryBound(to: UInt8.self), count: count))
        }
    }
}
````

````swift
import Foundation
import VirtioGPU
import Virtualization
import os

/// The host side of a virtio GPU for a Linux machine (roadmap 0014, ADR-NNNN), on the framework's custom virtio devices, which
/// need macOS 27. The framework calls it on the device queue, which is the main queue, so its state is main-actor state. The
/// library decides everything about a request (`GPUDeviceState.serve`); this class gives it the framework's queue elements and
/// guest memory, passes the pictures and cursor changes on to its sinks, and tells the guest when the display changed.
@available(macOS 27.0, *)
@MainActor
final class CustomGPUDevice: NSObject, VZCustomVirtioDeviceConfigurationDelegate, VZCustomVirtioDeviceDelegate {
    /// Where the guest's picture goes: each new picture of the scanout and each change of the guest's cursor. Both run on the
    /// main actor, inside the device's handling of a request, so they must not block.
    struct Sinks {
        var showFrame: @MainActor (ScanoutUpdate) -> Void
        var showCursor: @MainActor (CursorUpdate) -> Void
    }

    /// What can go wrong with a request, each logged once so that a guest cannot make the log grow.
    private enum Trouble {
        case oversized
        case unreadable
        case unanswered
        case writeFailed
    }

    private let sinks: Sinks
    private var state: GPUDeviceState
    private var device: VZCustomVirtioDevice?
    private var logged: Set<Trouble> = []

    init(limits: GPULimits = GPULimits(), sinks: Sinks) {
        state = GPUDeviceState(limits: limits)
        self.sinks = sinks
    }

    /// Resizes the display the guest sees: the next display-information answer reports `width` × `height`, and the guest is told
    /// to ask for it by setting the display event in the configuration space. Returns `false` and changes nothing for a size
    /// the library refuses (`GPULimits.allowsDisplay`).
    func requestDisplaySize(width: UInt32, height: UInt32) async throws -> Bool {
        guard state.setDisplaySize(width: width, height: height) else { return false }
        if let device {
            let space = GPUConfigSpace(eventsRead: GPUWire.eventDisplay, eventsClear: 0, scanoutCount: 1, capsetCount: 0)
            try await device.update(VZVirtioDeviceSpecificConfiguration(configurationData: Data(space.bytes)))
        }
        return true
    }

    func customVirtioConfiguration(_ configuration: VZCustomVirtioDeviceConfiguration, didCreateDevice device: VZCustomVirtioDevice) {
        device.delegate = self
        self.device = device
    }

    func customVirtioDevice(_ device: VZCustomVirtioDevice, didReceiveNotificationFor queue: VZVirtioQueue) {
        let kind: GPUQueueKind = queue.queueIndex == GPUWire.cursorQueue ? .cursor : .control
        let memory = GuestMemoryMapping(device: device)
        // Every element is taken before the method returns: a guest that notifies once does not notify again for them.
        while let element = queue.nextElement() {
            let outcome = state.serve(GuestQueueElement(element: element), on: kind, memory: memory) { handled in
                self.deliver(handled)
            }
            note(outcome)
        }
    }

    /// A reset forgets the guest's resources, scanout and cursor; the size the host chose for the display stays.
    func customVirtioDeviceWillReset(_ device: VZCustomVirtioDevice) {
        state.reset()
    }

    private func deliver(_ handled: HandledCommand) {
        if let frame = handled.scanoutUpdate { sinks.showFrame(frame) }
        if let cursor = handled.cursorUpdate { sinks.showCursor(cursor) }
    }

    private func note(_ outcome: ServeOutcome) {
        switch outcome {
        case .handled(let answer):
            note(answer)
        case .oversized(let length, let answer):
            report(.oversized, "A request of \(length) bytes was refused: it is more than the GPU device reads")
            note(answer)
        case .unreadable(let length, let error):
            report(.unreadable, "Couldn't read a request of \(length) bytes (\(error.logKind))")
        }
    }

    private func note(_ answer: AnswerStatus) {
        switch answer {
        case .written, .notNeeded:
            break
        case .didNotFit(let needed, let available):
            report(.unanswered, "An answer of \(needed) bytes didn't fit the \(available) the guest left; nothing was written")
        case .failed(let error):
            report(.writeFailed, "Couldn't write an answer (\(error.logKind))")
        }
    }

    private func report(_ trouble: Trouble, _ message: String) {
        guard logged.insert(trouble).inserted else { return }
        Log.display.notice("\(message, privacy: .public)")
    }
}
````

````swift
import Foundation
import VirtioGPU
import Virtualization

@available(macOS 27.0, *)
extension CustomGPUDevice {
    /// The device as the machine's configuration takes it (`customVirtioDevices`): the virtio GPU of the library's identity, a
    /// control and a cursor queue, only `VIRTIO_F_VERSION_1` offered (two-dimensional, no optional feature of its own), one
    /// scanout and no capability set, and no save and restore. The framework's provider keeps this object weakly, so whoever
    /// makes the machine holds it for as long as the machine lives.
    func makeConfiguration() -> VZCustomVirtioDeviceConfiguration {
        let configuration = VZCustomVirtioDeviceConfiguration()
        configuration.supportsSaveRestore = false
        configuration.deviceID = GPUWire.deviceID
        configuration.virtioQueueCount = GPUWire.queueCount
        (configuration.pciClassID, configuration.pciSubclassID) = (GPUWire.pciClassID, GPUWire.pciSubclassID)
        configuration.mandatoryFeatures.subset1 = GPUWire.versionOneFeatureSubset1
        let space = GPUConfigSpace(eventsRead: 0, eventsClear: 0, scanoutCount: 1, capsetCount: 0)
        configuration.deviceSpecificConfiguration = VZVirtioDeviceSpecificConfiguration(configurationData: Data(space.bytes))
        configuration.provider = VZCustomVirtioDeviceDelegateProvider(deviceQueue: .main, delegate: self)
        return configuration
    }
}
````
