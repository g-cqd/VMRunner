# F01 — A forced `MaxRuntimeMinutes` of 0 means no limit

Model: haiku · Effort: low · Worktree: yes, `WT = ~/Developer/g-cqd/VMRunner-chains/f-followups` (branch `chain/f-followups`) · Chain: F, card 1 of 12 (first; next F02)

Anchors: locate every edit by its text (`grep -nF`), never by a line number. Verified on `main` at `a98fd14`.

Why (owner decision, 2026-10-22): a configuration profile that forces `MaxRuntimeMinutes` to 0 imposes no cap. Today
`ManagedPreferences.init(forcedValue:)` turns every forced value that is not a whole number from 15 to 1440 into 15, 0
included. After this card a forced whole number 0 leaves `maxRuntimeMinutes` nil, so `isLocked(.maxRuntimeMinutes)` is false
(the stepper stays unlocked) and `clamp` leaves the machine's own limit alone. Every other bad value still becomes 15: a
Boolean, a string, a negative number, 1 to 14, more than 1440. A Boolean needs care: a forced `false` reaches the app as a
number that `as? Int` reads as 0, so it is told apart first (`CFGetTypeID` against `CFBooleanGetTypeID()`), and stays 15.
A forced `<real>0</real>` bridges to the whole number 0 and also means no limit. `isLocked` and `clamp` need no change: both
already treat nil as "not restricted".

```swift
    /// The limit a forced `MaxRuntimeMinutes` sets. 0 sets none: the organisation imposes no cap, and the control stays
    /// unlocked. Any other value that is not a whole number from 15 to 1440 (a Boolean, a string, a negative number, a
    /// number out of range) becomes the shortest limit, 15 minutes: a value of the wrong type restricts.
    private static func runtimeLimit(forced value: Any) -> Int? {
        // A Boolean bridges to 0 or 1 as a number: tell it apart first, so a forced `false` never reads as no limit.
        guard CFGetTypeID(value as CFTypeRef) != CFBooleanGetTypeID(), let minutes = value as? Int else {
            return EditorLimits.runtimeStepMinutes
        }
        if minutes == 0 { return nil }
        let offered = EditorLimits.runtimeStepMinutes...EditorLimits.runtimeMinutes.upperBound
        return offered.contains(minutes) ? minutes : EditorLimits.runtimeStepMinutes
    }
```
