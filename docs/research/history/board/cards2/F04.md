# F04 — Delete the install clones a crashed macOS setup left in the image cache, at launch

Model: haiku · Effort: low · Worktree: yes, `WT = ~/Developer/g-cqd/VMRunner-chains/f-followups` (branch `chain/f-followups`) · Chain: F, card 4 of 12 (after F03; next F05)

Anchors: locate every edit by its text (`grep -nF`), never by a line number. Verified on `main` at `a98fd14`.

Why (read from the code): `Provisioner.provisionMac` reads its own clone of a downloaded restore image,
`ImageStore.installCopy(of:)`, a hidden file named `.install-<UUID>-<name>` made **beside the cached file**, and deletes it in
a `defer`. A crash or a forced quit skips the `defer`: the clone stays, hidden, and holds the blocks of a 20 GB image that
the cache may drop later. After this card the app deletes such leftovers once, at launch.

Where the clones are: beside the cached file, so in a checksum folder of the cache (`Images/<sha256>/.install-...`), or
directly in `Images` for a file of the old flat cache. The sweep therefore looks directly in the images directory and in
each real folder directly inside it (one level, never deeper). It deletes only regular files whose name starts with
`.install-`; a link (to a file or to a folder) is never followed and never deleted, and a folder with that prefix is left.

Launch, not the start of a macOS setup, and why: at launch no setup of this app can be running yet, so every clone found is
a leftover. At the start of a setup, another setup of the same app may be installing from its own clone at that moment, and
the sweep would delete the file its installer is reading. Launch costs one listing of the cache folders.

    /// Deletes the install clones (`installCopy(of:)`) that a setup left behind when the app stopped in the middle of it:
    /// each holds the blocks of a restore image the cache may since have dropped. Looks directly in `imagesDirectory` and in
    /// each real folder directly inside it, where the clones are made. Deletes only regular files whose name starts with
    /// `.install-`; never follows a link and never deletes one. Run at launch, before any setup can have made a clone.
    static func sweepInstallClones(in imagesDirectory: URL = AppPaths.images) {
        let fileManager = FileManager.default
        func entries(of folder: URL) -> [URL] {
            (try? fileManager.contentsOfDirectory(at: folder, includingPropertiesForKeys: nil)) ?? []
        }
        // `attributesOfItem` describes a link itself and does not follow it.
        func isFolder(_ url: URL) -> Bool {
            (try? fileManager.attributesOfItem(atPath: url.path))?[.type] as? FileAttributeType == .typeDirectory
        }
        for folder in [imagesDirectory] + entries(of: imagesDirectory).filter(isFolder) {
            for entry in entries(of: folder) where entry.lastPathComponent.hasPrefix(".install-") {
                guard (try? regularFileExists(at: entry)) == true else { continue }
                try? fileManager.removeItem(at: entry)
            }
        }
    }
```

    @Test func theLaunchSweepDeletesOnlyLeftOverInstallClones() throws {
        let fileManager = FileManager.default
        let images = try scratchDirectory()
        defer { try? fileManager.removeItem(at: images) }
        let outside = try scratchDirectory()
        defer { try? fileManager.removeItem(at: outside) }
        let folder = images.appending(path: String(repeating: "a", count: 64), directoryHint: .isDirectory)
        try fileManager.createDirectory(at: folder, withIntermediateDirectories: true)
        let cached = folder.appending(path: "Restore.ipsw")
        try Data("image".utf8).write(to: cached)
        let nestedClone = try ImageStore.installCopy(of: cached)
        let flatClone = images.appending(path: ".install-1-Restore.ipsw")
        try Data("left over".utf8).write(to: flatClone)
        // Kept: a link with the prefix, the file it points to, a folder with the prefix, a clone two levels down, and the
        // files behind a link to a folder.
        let target = outside.appending(path: ".install-2-elsewhere.ipsw")
        try Data("not ours".utf8).write(to: target)
        let link = images.appending(path: ".install-3-link.ipsw")
        try fileManager.createSymbolicLink(at: link, withDestinationURL: target)
        let prefixedFolder = images.appending(path: ".install-4-folder", directoryHint: .isDirectory)
        try fileManager.createDirectory(at: prefixedFolder, withIntermediateDirectories: true)
        let deeper = folder.appending(path: "sub", directoryHint: .isDirectory).appending(path: ".install-5-deep.ipsw")
        try fileManager.createDirectory(at: deeper.deletingLastPathComponent(), withIntermediateDirectories: true)
        try Data("deeper".utf8).write(to: deeper)
        try fileManager.createSymbolicLink(at: images.appending(path: "linked"), withDestinationURL: outside)

        #expect((try? fileManager.destinationOfSymbolicLink(atPath: link.path)) != nil, "and the link itself stays")
        #expect(fileManager.fileExists(atPath: prefixedFolder.path) && fileManager.fileExists(atPath: deeper.path))
    }

```
