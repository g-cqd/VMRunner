# D05 — F3, part 2: Rocky Linux 10 checks its signed CHECKSUM list against a pinned key (still a candidate)

Model: haiku · Effort: low · Worktree: yes, `WT = ~/Developer/g-cqd/VMRunner-chains/d-security` (branch `chain/d-security`) · Chain: D, card 5 of 22 (after D04; next D06)

Anchors: locate every edit by its text (`grep -n`), never by a line number. D04 changed some of these files; where D04 added
lines, this card names them by their content, not by their layout (swift-format may have reflowed them).

Why: Rocky Linux publishes, per major version, one `CHECKSUM` list of every ISO with a detached signature `CHECKSUM.asc` (and a
per-ISO `<iso>.CHECKSUM`, which the app used until now, unsigned). The key was read on 2026-10-22 from
`https://download.rockylinux.org/pub/rocky/RPM-GPG-KEY-Rocky-10`: RSA 4096, created 2025-05-19, no expiry, fingerprint
`FC22 6859 C086 0BF0 DDB9 5B08 5B10 6C73 6FED FC85`, which `https://rockylinux.org/keys` publishes; `gpg` verified the real
`CHECKSUM` with `CHECKSUM.asc` (both captured whole into `cards2/fixtures/raw/`). The provider switches to the shared, signed
list (the release is chosen from it; the unsigned listing and the per-ISO files are no longer read), serves the series `10`
and refuses anything older than `10.2`. It stays a candidate until D07.

    private static let rockyFloors = [10: "10.2"]

    /// The CHECKSUM file lists every ISO of a major version and has a detached signature (`CHECKSUM.asc`) made by that version's
    /// key; a version the app pins no key for is refused, not read without a signature.
    static func rocky(release: Int, flavor: String) -> Self {

            iso: .newest(prefix: "Rocky-", suffix: "-aarch64-\(flavor).iso"),

/// Rocky Linux signs one CHECKSUM list per major version with a detached signature, with one key per major version.
struct RockyLinuxProviderTests {
    @Test func theRealChecksumFileVerifiesAgainstThePinnedKey() throws {
        let check = try PGP.Check.detached(
            Array(SignedVendorFiles.rockyLinuxSignature.utf8), keys: [PGP.PinnedKeys.rockyLinux10.publicKey()], now: pgpGoldenNow)
