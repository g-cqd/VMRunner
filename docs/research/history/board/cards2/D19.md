## Change

1. `PGP+Signature.swift`: directly after the closing brace of `static func parse(packets: [UInt8]) throws(Failure) -> Self`, insert:

```swift

        /// The most signature packets a cleartext message may carry. Debian's archive signs its `InRelease` three times.
        static let maximumSignatures = 4

        /// The signatures in `packets` that this reader understands, for a cleartext message several keys signed (ADR-0055).
        /// Every packet must be a signature packet with sound framing; one this reader does not understand (another version,
        /// another algorithm such as EdDSA) is skipped and never trusted.
        /// - Throws: `Failure` for no packet, more than `maximumSignatures`, a packet that is not a signature, or bad framing.
        static func parseEach(packets: [UInt8]) throws(Failure) -> [Self] {
            var reader = ByteReader(packets)
            var bodies: [[UInt8]] = []
            while !reader.isAtEnd { bodies.append(try packetBody(&reader)) }
            guard !bodies.isEmpty else { throw .malformedSignature("the file has no packet") }
            guard bodies.count <= maximumSignatures else { throw .signatureCount(bodies.count) }
            return bodies.compactMap { body in try? parse(body: body) }
        }
```

   with

```swift
        /// The text of a cleartext-signed document, once the one signature a pinned key made verifies over exactly that text.
        /// Several keys may sign one message (Debian's archive does, ADR-0055): signatures by keys that are not pinned, and ones
        /// this reader does not understand, are skipped and never trusted; none, or more than one, by a pinned key is refused.
        static func verifyClearSigned(_ document: [UInt8], keys: [RSAPublicKey], now: Date) throws(Failure) -> [UInt8] {
            let message = try Armor.decodeClearSigned(document)
            let readable = try Signature.parseEach(packets: message.signature)
            guard !readable.isEmpty else { throw .malformedSignature("no signature this app can read") }
            let pinned = readable.filter { signature in keys.contains { $0.fingerprint == signature.issuerFingerprint } }
            guard pinned.count <= 1 else { throw .signatureCount(pinned.count) }
            guard let signature = pinned.first else {
                throw .unpinnedSigner(readable.map { $0.issuerFingerprint.hexString.uppercased() }.joined(separator: ", "))
            }
            guard message.hashNames.contains(signature.hash.headerName) else {
                throw .malformedArmor("the Hash header does not name the hash the signature uses")
            }
            try Self(signature, expecting: 0x01, keys: keys, now: now).verify(message.canonicalText)
            return message.text
        }
```

3. Create `docs/adr/0055-debian-netboot-is-checked-through-the-archives-signed-release-file.md` with exactly:

```markdown
---
status: proposed
date: 2026-10-22
---
# 0055 — Debian netboot is checked through the archive's signed Release file

This ADR amends [ADR-0023](0023-pinned-vendor-keys-vouch-for-installer-checksums.md): its decision 2 refuses a file with more
than one signature, and its "What this does not decide" leaves signatures made by a subkey and the Debian archive's signed
Release file for the netboot index open. Everything else in ADR-0023 stands.

## Context

The Debian netboot image's `SHA256SUMS` (`deb.debian.org`, `dists/stable/main/installer-arm64/current/images/`) is signed by
nothing of its own. The archive's `dists/stable/InRelease` lists the SHA-256 of every index of the suite, this file among
them, and is a cleartext message signed three times: by the signing subkey of the Debian 12 archive key, by the signing subkey
of the Debian 13 archive key, and by the Debian 13 release key (EdDSA, which the verifier does not read). Read on 2026-10-22:
the Debian 13 archive key `04B5 4C3C DCA7 9751 B16B C6B5 2256 29DF 75B1 88BD` is published on ftp-master.debian.org/keys.html;
its key file binds the RSA-4096 signing subkey `B8E5 F131 76D2 A7A7 5220 0280 78DB A3BC 47EF 2265`, which expires on
2035-03-28; an independent OpenPGP tool verified that day's `InRelease` with it, and the `SHA256SUMS` it lists matched the served file.

## Decision

1. **A cleartext message may carry up to four signatures.** Each must be a signature packet with sound framing. Signatures the
   verifier does not understand, and those by keys not pinned for the file, are skipped and never trusted; exactly one must be
   by a pinned key, and it is verified as before. A detached signature still carries exactly one.
2. **A signing subkey may be pinned like a key** when its binding to the vendor's primary key was checked when it was pinned:
   the primary key's fingerprint on the vendor's page, the binding in the vendor's key file. The app reads no key file at run
   time; the pin is the subkey's own constants and fingerprint, with its expiry (ADR-0054).
3. **The Debian netboot image is a signed provider.** Its `SHA256SUMS` is believed when its SHA-256 is the one the `InRelease`
   of the same suite lists for its path, that `InRelease` is signed by the pinned Debian 13 archive signing subkey, names the
   release `trixie` and is not older than point release 13.7.

## Consequences

A compromised mirror or CDN can no longer substitute the netboot image and its index together. When Debian 14 becomes stable,
the suite's codename and archive key change, and the image fails closed until the app pins the new key; the same happens on
2035-03-28 when the subkey expires, and the expiry test warns 90 days ahead. The real `InRelease` is 140 KB and changes with
every point release, so the tests use synthetic messages and the real one was checked by hand; a real-network check on a Mac
is owed. Nothing checks how fresh the `InRelease` is: a mirror can replay an older genuine one, with the matching older index,
down to the 13.7 floor, so the floor is the only bound on how old an installer can be.

## What this does not decide

Reading the release key's EdDSA signature; Debian netinst (still blocked by its redirect to a mirror); revocation.
```

```swift
import Foundation
import Testing

@testable import VMRunner

/// A cleartext message several keys signed, as Debian's archive signs its `InRelease` (ADR-0055).
struct PGPSeveralSignersTests {
    private let signer: TestSigner
    private let other: TestSigner

    init() throws {
        signer = try SharedSigner.get()
        other = try TestSigner()
    }

    /// A cleartext message of `lines` whose armored block holds `bodies`, one signature packet each.
    private func message(_ lines: [String], bodies: [[UInt8]]) -> [UInt8] {
        let text = "-----BEGIN PGP SIGNED MESSAGE-----\nHash: SHA256\n\n" + lines.joined(separator: "\n") + "\n"
        return Array(text.utf8) + TestSigner.armor(bodies.flatMap { TestSigner.packet($0) })
    }

    private func body(_ key: TestSigner, over lines: [String]) throws -> [UInt8] {
        try key.signatureBody(over: Array(lines.joined(separator: "\r\n").utf8), SignatureDraft(type: 0x01))
    }

    @Test func theOneSignatureByAPinnedKeyIsCheckedAndTheOthersAreSkipped() throws {
        let lines = ["Codename: trixie", "Version: 13.7"]
        let foreign = try body(other, over: lines)
        let mine = try body(signer, over: lines)
        let text = try PGP.Check.verifyClearSigned(message(lines, bodies: [foreign, mine]), keys: [signer.key], now: pgpTestNow)
        #expect(utf8String(text) == "Codename: trixie\nVersion: 13.7")
    }

    @Test func noneOrTwoByPinnedKeysAndTooManyPacketsAreRefused() throws {
        let lines = ["a"]
        let foreign = try body(other, over: lines)
        let mine = try body(signer, over: lines)
        let unpinned = message(lines, bodies: [foreign])
        #expect(throws: PGP.Failure.self) { try PGP.Check.verifyClearSigned(unpinned, keys: [signer.key], now: pgpTestNow) }
        let twice = message(lines, bodies: [mine, mine])
        #expect(throws: PGP.Failure.signatureCount(2)) { try PGP.Check.verifyClearSigned(twice, keys: [signer.key], now: pgpTestNow) }
        let crowd = message(lines, bodies: Array(repeating: foreign, count: 4) + [mine])
        #expect(throws: PGP.Failure.signatureCount(5)) { try PGP.Check.verifyClearSigned(crowd, keys: [signer.key], now: pgpTestNow) }
    }

    @Test func aSignatureThisReaderCannotReadIsSkippedEvenWhenItNamesThePinnedKey() throws {
        let lines = ["a"]
        let mine = try body(signer, over: lines)
        var eddsa = mine
        eddsa[2] = 22  // the public-key algorithm byte: EdDSA, as Debian's release key signs
        let document = message(lines, bodies: [eddsa, mine])
        #expect(utf8String(try PGP.Check.verifyClearSigned(document, keys: [signer.key], now: pgpTestNow)) == "a")
        let alone = message(lines, bodies: [eddsa])
        #expect(throws: PGP.Failure.malformedSignature("no signature this app can read")) {
            try PGP.Check.verifyClearSigned(alone, keys: [signer.key], now: pgpTestNow)
        }
    }

    @Test func aDetachedSignatureStillCarriesExactlyOne() throws {
        let data = Array("x".utf8)
        let one = try signer.signatureBody(over: data)
        let armored = TestSigner.armor(TestSigner.packet(one) + TestSigner.packet(one))
        #expect(throws: PGP.Failure.signatureCount(2)) { try PGP.Check.detached(armored, keys: [signer.key], now: pgpTestNow) }
    }
}
```
