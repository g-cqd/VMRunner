The start and stop paths already work for a container: `LibraryControlMachines` calls `startAndWait` and `stopAndWait`, which drive the same `VMController` and the routing factory, so the machine's agent access switch and the organisation's `AllowControlService` lock apply to it unchanged, a forced stop is the container's kill, and a refused start (`AllowContainers` off, a missing runner) comes back as the controller's message, which the adapter already maps to a refusal. This card adds the one thing missing, `workload` in the list, and the tests that pin those paths for a container. Decisions:
- **`workload` is additive.** `machines.list` and `machines.state` answers hold one more member per machine, `"workload": "vm"` or `"workload": "container"`; the members they always had are the same. `ControlMachine.workload` defaults to `"vm"` in its initializer, and a decoder that finds no `workload` (an answer from an older service) reads `"vm"`, so a new `vmr` talks to an old app. A client that does not know the member ignores it (the JSON decoders in use do not reject unknown members; the service's own request parser is not involved, since `workload` is only in answers).
- **`guest` stays `"linux"` for a container**, and the doc comment on `ControlMachine.guest` says why: `guest` has only ever named an operating system (`macOS` or `linux`), a container runs a Linux userland, and a client that switches on `guest` keeps working. Its schema change is documented where the schema is documented: the doc comments of `ControlMachine`, the MCP tool description of `machines_list` and `machines_stop`, and the control help topic's advanced paragraph. The `vmr control list` text line (id, state, guest and name) is NOT changed; `vmr control list --json` and the MCP tool carry `workload`.
- **Nesting.** The member is a string inside the machine object, so a `machines.list` answer is still four deep (the answer, `result`, the `machines` array, a machine), under `ControlAnswer.deepestNesting` (8); a test counts it, and the socket test reads a real answer through `ControlClient`, which refuses a deeper one.
- **Start and stop of a container** need no new code: the adapter requires agent access and the policy of the control service as for any machine. `machines.start` of a container answers `{"id":"<uuid>","state":"running"}` once the runner says the container is up; `machines.stop` answers `{"id":"<uuid>","state":"shuttingDown"}` at once and the container ends by itself (the runner gets its stop line), and with `"force": true` kills it and answers `{"id":"<uuid>","state":"stopped"}`. A start the organisation forbids is the JSON-RPC error `-32004` with the message `Refused: Your organisation doesn't allow containers on this Mac. Ask your administrator to change it.`; it never hangs or crashes, and the machine stays stopped and listed.
- **Tests**: `ContainerControlTests` (the adapter over a library that holds a container machine, a fake runner script, `RoutingMachineFactory(containers: ContainerMachineFactory(runner:policy:))`): the list says `workload` is `container`, with `guest` `linux` and the right state before a start, while it runs and after a stop; a clean stop asks the container and it ends stopped; a forced stop ends a runner that ignores its stop line and SIGTERM; agent access off refuses a start and a stop and the runner is never run; the organisation keeping the service off lists nothing and starts nothing; `AllowContainers` off refuses a start with the message and leaves the machine stopped and listed, runner never run; a virtual machine's entry is what it was plus `workload: "vm"`. `ContainerControlSocketTests` (the real `ControlService` and `ControlClient` on a short private folder under `/tmp`, one connection per call made off the main actor): list, start, state and a forced stop of a container with the exact answer shapes, and a forbidden start with its error. `ControlMachineSchemaTests` (no app): the members written, an old answer without `workload` read as `vm`, a newer unknown member ignored, the depth of a list.

/// The shape of a machine in the service's answers: `workload` was added after the other members, so old and new meet.
struct ControlMachineSchemaTests {
    private let id = UUID()

    private func json(_ machine: ControlMachine) throws -> [String: Any] {
        let encoder = JSONEncoder()
        encoder.outputFormatting = [.sortedKeys]
        let object = try JSONSerialization.jsonObject(with: encoder.encode(machine))
        return try #require(object as? [String: Any])
    }

    @Test
    func aMachineIsWrittenWithItsWorkloadAndTheMembersItAlwaysHad() throws {
        let box = ControlMachine(id: id, name: "box", guest: "linux", state: .running, agentAccess: true, workload: "container")
        let written = try json(box)
        #expect(Set(written.keys) == ["id", "name", "guest", "state", "agentAccess", "workload"])
        #expect(written["workload"] as? String == "container" && written["guest"] as? String == "linux")
        #expect(
            try json(ControlMachine(id: id, name: "vm", guest: "macOS", state: .stopped, agentAccess: false))["workload"] as? String == "vm"
        )
    }

    @Test
    func anAnswerFromAServiceThatPredatesContainersReadsAsAVirtualMachine() throws {
        let old = #"{"agentAccess":true,"guest":"linux","id":"\#(id.uuidString)","name":"old","state":"stopped"}"#
        let machine = try JSONDecoder().decode(ControlMachine.self, from: Data(old.utf8))
        #expect(machine == ControlMachine(id: id, name: "old", guest: "linux", state: .stopped, agentAccess: true, workload: "vm"))
    }

    @Test
    func aMemberANewerServiceAddsIsIgnored() throws {
        let newer =
            #"{"agentAccess":false,"extra":{"a":1},"guest":"macOS","id":"\#(id.uuidString)","name":"n","state":"paused","workload":"vm"}"#
        let machine = try JSONDecoder().decode(ControlMachine.self, from: Data(newer.utf8))
        #expect(machine.state == .paused && machine.workload == "vm")
    }

    @Test
    func theWorkloadMakesTheListNoDeeperThanTheClientReads() throws {
        let box = ControlMachine(id: id, name: "box", guest: "linux", state: .running, agentAccess: true, workload: "container")

import ControlProtocol
import Foundation
import TestKit
import Testing

@testable import VMRunner

/// A container machine in the library, with a shell script for the runner and a flag file the script leaves when it is run.
/// Nothing here starts a container or the real runner.
@MainActor
private struct ControlRig {
    static let ready = #"{"event":"phase","name":"run","seconds":0}"#
    /// Says it is ready, then waits for a `stop` line (exit 75) or the end of its input (exit 76).
    static let waitsForStop = "echo '\(ready)'\nread line || exit 76\n[ \"$line\" = stop ] && exit 75\nexit 1"
    /// Says it is ready, ignores its input and SIGTERM, then sleeps: only SIGKILL ends it.
    static let ignoresEverything = "trap '' TERM\necho '\(ready)'\nexec sleep 30"

    let directory: URL
    let library: VMLibrary
    let controller: VMController
    let config: VMConfig

    init(script: String, containersAllowed: Bool = true, agentAccess: Bool = true) throws {
        directory = try scratchDirectory()
        let runner = directory.appending(path: "runner.sh")
        try Data("#!/bin/sh\n: > \"$(dirname \"$0\")/ran\"\n\(script)\n".utf8).write(to: runner)
        try FileManager.default.setAttributes([.posixPermissions: 0o700], ofItemAtPath: runner.path)
        let machines = directory.appending(path: "Machines", directoryHint: .isDirectory)
        try FileManager.default.createDirectory(at: machines, withIntermediateDirectories: true)
        let policy = ManagedPreferences(forcedValue: {
            $0 == ManagedKey.allowContainers.rawValue && !containersAllowed ? false as Any : nil
        })
        let router = RoutingMachineFactory(
            virtualMachines: FakeFactory(), containers: ContainerMachineFactory(runner: runner, policy: { policy }))
        let controller = VMController(factory: router, latency: LatencyActivity(host: ProcessInfo.processInfo, isEnabled: false))
        self.controller = controller
        library = VMLibrary(machinesDirectory: machines, saveDelay: .seconds(3600), makeController: { controller })
        var proposed = VMConfig.newContainer(name: "box")
        proposed.agentAccess = agentAccess
        try library.add(proposed)
        config = library.machine(proposed.id) ?? proposed
    }

    var id: UUID { config.id }
    var adapter: LibraryControlMachines { LibraryControlMachines(library: library) }
    /// Whether the runner script was run at all.
    var runnerRan: Bool { FileManager.default.fileExists(atPath: directory.appending(path: "ran").path) }

    func remove() { try? FileManager.default.removeItem(at: directory) }

    /// Calls made when the workload reports it stopped, after the controller has handled the report.
    func watchStops() throws -> AsyncEventProbe<String> {
        let workload = try #require(controller.guest as? ContainerWorkload)
        let probe = AsyncEventProbe<String>()
        let stopped = workload.onGuestStopped
        workload.onGuestStopped = {
            stopped?()
            probe.record("stopped")
        }
        return probe
    }
}

/// The same machine reached through the service's socket, as a script or an agent reaches it.
@MainActor
@Suite(.serialized, .timeLimit(.minutes(1)))
struct ContainerControlSocketTests {
    private func shortFolder() throws -> URL {
        let url = URL(filePath: "/tmp", directoryHint: .isDirectory).appending(
            path: "vmrs-\(UUID().uuidString)", directoryHint: .isDirectory)
        try FileManager.default.createDirectory(at: url, withIntermediateDirectories: false, attributes: [.posixPermissions: 0o700])
        return url
    }

    /// One call on its own connection, made off the main actor so the app can answer it.
    private func call(_ path: String, _ method: String, _ params: [String: RPCValue]) async throws -> ControlAnswer {
        try await Task.detached {
            let client = try ControlClient.connect(to: path)
            defer { client.close() }
            return try client.call(method, params: params)
        }.value
    }

    /// Runs `body` against a service over the rig's library on a private socket, and stops the service afterwards.
    private func withService(
        _ rig: ControlRig, _ body: (_ call: (String, [String: RPCValue]) async throws -> ControlAnswer) async throws -> Void
    ) async throws {
        let root = try shortFolder()
        defer { try? FileManager.default.removeItem(at: root) }
        let service = ControlService(directory: root.appending(path: "Control", directoryHint: .isDirectory), machines: rig.adapter)
        let secret = try service.tokenStore().create(name: "t", capabilities: [.list, .state, .start, .stop]).secret
        await service.setRunning(true)
        do {
            let path = try #require(service.socketPath)
            try await body { method, params in
                try await self.call(path, method, params.merging(["token": .string(secret)]) { first, _ in first })
            }
        } catch {
            await service.setRunning(false)
            throw error
        }
        await service.setRunning(false)
    }

    private func object(_ answer: ControlAnswer) throws -> [String: Any] {
        let data = try #require(answer.result)
        return try #require(try JSONSerialization.jsonObject(with: data) as? [String: Any])
    }

    @Test func aScriptListsStartsAndStopsAContainerThroughTheSocket() async throws {
        let rig = try ControlRig(script: ControlRig.ignoresEverything)
        defer { rig.remove() }
        let machine: [String: RPCValue] = ["machine": .string(rig.id.uuidString)]

        try await withService(rig) { call in
            let list = try await call("machines.list", [:])
            let machines = try #require(try object(list)["machines"] as? [[String: Any]])
            #expect(machines.count == 1)
            let entry = try #require(machines.first)
            #expect(Set(entry.keys) == ["id", "name", "guest", "state", "agentAccess", "workload"])
            #expect(entry["workload"] as? String == "container" && entry["guest"] as? String == "linux")
            #expect(entry["state"] as? String == "stopped" && entry["name"] as? String == "box")

            let started = try await call("machines.start", machine)
            #expect(try object(started) as NSDictionary == ["id": rig.id.uuidString, "state": "running"])
            let running = try await call("machines.state", machine)
            #expect(try object(running)["state"] as? String == "running")

            let stopped = try await call("machines.stop", machine.merging(["force": .bool(true)]) { first, _ in first })
            #expect(try object(stopped) as NSDictionary == ["id": rig.id.uuidString, "state": "stopped"])
        }
        #expect(rig.controller.state == .stopped && rig.controller.guest == nil)
    }

    @Test func aStartTheOrganisationForbidsAnswersARefusalWithItsMessage() async throws {
        let rig = try ControlRig(script: ControlRig.waitsForStop, containersAllowed: false)
        defer { rig.remove() }

        try await withService(rig) { call in
            let refused = try await call("machines.start", ["machine": .string(rig.id.uuidString)])
            #expect(refused.errorCode == -32004 && refused.result == nil)
            #expect(refused.errorMessage == "Refused: " + ManagedPreferences.containersDeniedMessage)
            let state = try await call("machines.state", ["machine": .string(rig.id.uuidString)])
            #expect(try object(state)["state"] as? String == "stopped")
        }
        #expect(!rig.runnerRan)
    }
}
