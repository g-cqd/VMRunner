Why: ADR-0013 lets an organisation lock, through managed preferences, the channels from the Mac into a guest
(`AllowSharedFolders`, `AllowClipboardSharing`, `AllowMicrophone`, `AllowHostInformation`). A provisioning seed carries the
user's files into the guest and runs them as root: the same kind of channel, so a key is natural (INDEX-L decision 6). It
follows `AllowControlService` exactly: forced to anything but `true`, every machine loses its spec when the library loads,
adds or changes it (`clamp`), and the chooser is locked (`managedLock(.allowProvisioning)`, used by the editor in L08). The
existing test `theHelpNamesEveryKeyThatCanBeManaged` requires the help to name the key; ADR-0013 and roadmap 0013 list the
keys, so both get the new one.
