- **Model:** haiku, low. **Worktree:** yes (E). **Size:** about 100 lines (half is help text and tests).
- **Design:** for the app's own settings (`AppSetting`, E13) a forced value already wins when it is read, because managed
  preferences come first in the app's domain; what is missing is the lock. `ManagedPreferences` records which of them are
  forced, and `.managedLock(_: AppSetting)` locks the matching control. The menu toggle "Hide Toolbar in Full Screen" is
  only disabled (a lock icon does not belong in a menu item).
