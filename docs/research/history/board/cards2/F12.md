### The real-guest run of 2026-10-22

An authorised real-guest run on the app built from `main`, before this branch, observed: the host-information share mounts
in a Linux guest and is read-only; the NVMe disk, the disk serial number and the vendor prefixes of MAC addresses work on
NAT; the kill switch cuts the network card and gives it back; the vendors' signed files verify by an independent check with
`gpg`. Not observed: a partial battery, a real VPN, a macOS guest, a real configuration profile. It found four defects, each
fixed by one commit here. The host-information files vanished for about a second at each rewrite, because they were replaced
by rename; they are now rewritten in place. The kill switch logged nothing; it now logs each cut and reconnection with its
reason. The Alpine image of the catalog leaves the serial console silent, and the app cannot change its kernel command line;
the help, ADR-0052 and the automation study now say the guest must boot with `console=hvc0`, and how. Tests left empty
preferences files in the user's Library; they now use a suite in a scratch folder, since deleting such a file does not hold
(the system writes it back seconds later).

### Decisions

The owner decided that a forced `MaxRuntimeMinutes` of 0 means no limit; ADR-0013 records it and stays proposed. Leftover
install clones are deleted at launch, not when a macOS setup starts: at launch no setup can be running, while at the start
of one another setup may be reading its own clone. When the network card stays connected after the kill switch cuts it,
the machine stops with a message: the fail-closed default, until the owner chooses between stopping and only showing an
error.

### Not verified

A framework that refuses to take the attachment off a network card has never been seen, nor the stop that follows. Taking
the attachment off before the machine starts needs a real guest. The lock row of a managed setting in a real form, with a
real configuration profile. A macOS install interrupted by a crash, then the launch that removes its clone. A data
directory on a volume that is not APFS: read from the code, a macOS install there fails with the clone error. That writing
the host-information files in place ends the gaps a guest saw, and the new kill switch log lines, in a real run.

### Left for the owner

Whether a restriction the library wrote into a machine's file is undone when the organisation lifts it; accepting
ADR-0013; what the kill switch does when a cut fails.

### Cleaned
