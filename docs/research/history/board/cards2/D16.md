# D16 — F10, part 3: a macOS install reads its own clone of the restore image, never the shared cache file

Model: haiku · Effort: low · Worktree: yes, `WT = ~/Developer/g-cqd/VMRunner-chains/d-security` (branch `chain/d-security`) · Chain: D, card 16 of 22 (after D15; next D17)

Anchors: locate every edit by its text (`grep -n`), never by a line number. Verified on `main` at `73bceb0`.

Why (read from the code; this is how "clone the restore image instead of copying" is read, see INDEX-D): ADR-0031 made a Linux
machine boot from its own clone of the verified installer, so nothing that happens to the shared cache afterwards reaches it.
The macOS path still hands the cache file itself (`Images/<sha256>/<name>.ipsw`) to `VZMacOSRestoreImage.image(from:)` and to
`VZMacOSInstaller`, which read it for the whole install (many minutes), while another setup may replace or delete that file. A
copy-on-write clone under a name no other setup uses (`clonefile`, ADR-0003: instant, no space) is taken right after the
verified file is returned, the install reads the clone, and the clone is deleted when the install ends, however it ends. The
cache file is still discarded after a successful install, as before (ADR-0003 item 4). A file the user picked is read where it
is, as before. The install itself needs the virtualization entitlement and a real macOS restore, so the end-to-end check is the
owner's (INDEX-D); the unit tests cover the clone.
Basis of this reading (checked on `main`): the adversarial review lists "the installer was attached from a shared mutable cache
after being verified once" under downloads; ADR-0031 fixed that for Linux and its Consequences name only the old flat-cache
machines, so the macOS restore image is the remaining reader of the shared cache. Nothing copies the image today, so
"instead of copying" cannot mean replacing a copy. Known limit: a crash during the install leaves one hidden `.install-*`
clone in the cache folder; it shares blocks with the cache file until that is deleted, and clearing the downloaded images
removes it.

## Change

1. `ImageStore.swift`: directly after the closing brace of `static func keepInstaller(_ cached: URL, in bundle: VMBundle) throws -> URL`
   (still inside `enum ImageStore`), insert:

```swift

    /// A copy-on-write clone of the verified `file` beside it, under a name no other setup uses, for one install to read
    /// (ADR-0003, ADR-0031): the shared file may be replaced or removed while the install runs, the clone may not. The name
    /// keeps the file's own name at its end, so the extension is unchanged. The caller deletes the clone.
    /// - Throws: `SetupError.notARegularFile` for a link or another kind of entry, `SetupError.missingFile` when nothing is there.
    static func installCopy(of file: URL) throws -> URL {
        guard try regularFileExists(at: file) else { throw SetupError.missingFile(file.path) }
        let copy = file.deletingLastPathComponent().appending(path: ".install-\(UUID().uuidString)-\(file.lastPathComponent)")
        try APFS.clone(file, to: copy)
        return copy
    }
```

```swift
    @Test func anInstallReadsACloneOfItsOwnThatChangesToTheCachedFileDoNotReach() throws {
        let directory = try scratchDirectory()
        defer { try? FileManager.default.removeItem(at: directory) }
        let cached = directory.appending(path: "UniversalMac_26.1_25B78_Restore.ipsw")
        try Data("the verified restore image".utf8).write(to: cached)

        let copy = try ImageStore.installCopy(of: cached)
        #expect(copy.deletingLastPathComponent().path == cached.deletingLastPathComponent().path)
        #expect(copy.lastPathComponent.hasSuffix("-UniversalMac_26.1_25B78_Restore.ipsw") && copy.lastPathComponent.hasPrefix(".install-"))
        try Data("replaced".utf8).write(to: cached)
        #expect(try contents(of: copy) == "the verified restore image")
        #expect(try ImageStore.installCopy(of: cached) != copy, "each install gets a clone of its own")
    }

    @Test func aLinkOrANameWithNothingBehindItIsNeverClonedForAnInstall() throws {
        let directory = try scratchDirectory()
        defer { try? FileManager.default.removeItem(at: directory) }
        let target = directory.appending(path: "elsewhere.ipsw")
        try Data("x".utf8).write(to: target)
        let link = directory.appending(path: "UniversalMac.ipsw")
        try FileManager.default.createSymbolicLink(at: link, withDestinationURL: target)
        #expect(throws: SetupError.self) { try ImageStore.installCopy(of: link) }
        #expect(throws: SetupError.self) { try ImageStore.installCopy(of: directory.appending(path: "missing.ipsw")) }
    }
```
