## Decisions (read before editing; each is written so a reviewer can disagree with it)

1. **Nothing Linux-only to hide in the sheet.** The sheet has no cloud-init, Rosetta, serial-console or GPU control (those are editor rows), so "hide the Linux-only controls for Windows" needs no code here: the Windows branch of the sheet shows `WindowsMediaSection`, the shared resources section (processors, memory, disk) and the requirements panel. The Linux media section has an image picker (a catalog and "Other ISO") but no address field; the Windows section has neither.
2. **A source that is not a local file is refused in two places.** `NewMachineModel.makeConfig()` gives a Windows machine `.local(path)` or nothing (never a catalog or remote source, whatever `config.source` held), and `VMConfig.validate()` (so decode of `config.json` too) refuses a Windows config whose `source` is not `.local`: `"source must be a local file for a Windows machine"`. `NewMachineModel.create` validates a Windows config before adding it.
3. **The check reuses `Checksums.hexDigest`, which reads in 4 MiB chunks, not 1 MiB.** The repository already has a streamed SHA-256 (`Engine/Checksums.swift`: CryptoKit, `Task.detached`, cancellation, no symlink following, a chunk size measured fastest on an M3 for large files). A second hashing loop in this card would duplicate it (the analyzers' `dolly` step flags clones) for no gain, so the card calls it. This is the one place the card differs from "1 MiB chunks"; change `Checksums.chunkSize` in a later change if 1 MiB is wanted for every caller.
4. **The check runs before the machine exists, and cannot be skipped by a path the sheet has.** `createAfterVerifying(in:)` (what the Create button calls) hashes the installer first when an expected SHA-256 was typed, then adds the machine; a mismatch, a malformed text or a read error sets `creationError` and adds nothing. `create(in:)` stays synchronous for the other guests and for a Windows machine with no digest, and refuses a Windows machine that has a digest ("The installer's SHA-256 has not been checked yet.") so no caller makes one unchecked. Cancel and closing the sheet cancel the task; a cancelled check makes no machine and shows no message. The file can still change after the check: the check is of the file as it was when the machine was made (follow-up: none, the installer is a file the person owns).
5. **Typing is trimmed, case is ignored, anything else is malformed.** Spaces and line breaks around the digest are dropped, upper case is accepted, a "sha256:" prefix or an internal space is malformed (64 hexadecimal digits, nothing else). The message under the field appears while the text is malformed, and Create is disabled.
6. **The driver disc is optional and local.** It is a file from the open panel, stored as `driverDiscPath`, refused when its location cannot be stored (not absolute, too long) or lies inside the Machines folder. `VMLibrary.add` approves it read-only with the machine (it is in `hostGrants`). The sheet's Windows media header links to the guest-systems help topic until the help card gives Windows its own.
7. **Words.** `WindowsRequirements.lines` holds the six statements in the order of the panel; the TPM statement is the chain's fixed wording, verbatim. The notes beside the slots say only what the slot does.

```swift
import Foundation

/// The SHA-256 a person typed for an installer image they chose, and the check of the file against it. The check is optional:
/// an empty field means none was asked for. The hashing is `Checksums`', which streams the file off the main actor.
enum InstallerDigest {
    enum Failure: Error, Equatable, LocalizedError {
        /// The text is not 64 hexadecimal digits.
        case malformed
        case mismatch(expected: String, actual: String)

        var errorDescription: String? {
            switch self {
            case .malformed:
                "The expected SHA-256 must be 64 hexadecimal digits (0 to 9 and a to f). Check what you pasted, or clear the field."
            case .mismatch(let expected, let actual):
                "The installer image does not match the expected SHA-256. Expected \(expected), but the file is \(actual). "
                    + "Choose the right file, or correct the checksum."
            }
        }
    }

    /// The lowercase digest `text` spells, or nil when `text` is empty after trimming spaces and line breaks.
    /// - Throws: `Failure.malformed` for anything else that is not 64 hexadecimal digits.
    static func expected(from text: String) throws(Failure) -> String? {
        let trimmed = text.trimmingCharacters(in: .whitespacesAndNewlines)
        guard !trimmed.isEmpty else { return nil }
        guard trimmed.utf8.count == 64, trimmed.utf8.allSatisfy(\.isASCIIHexDigit) else { throw .malformed }
        return trimmed.lowercased()
    }

    /// What is wrong with `text` as an expected digest, or nil when it is empty or well formed.
    static func problem(in text: String) -> Failure? {
        do throws(Failure) {
            _ = try expected(from: text)
            return nil
        } catch {
            return error
        }
    }

    /// Hashes `file` and compares it with `text`. Does nothing, and does not open the file, when `text` is empty.
    /// - Returns: whether a comparison was made.
    /// - Throws: `Failure` for a malformed text or a different digest; the error of the read for a file that cannot be read.
    @discardableResult
    static func verify(_ file: URL, against text: String) async throws -> Bool {
        guard let expected = try expected(from: text) else { return false }
        let actual = try await Checksums.hexDigest(of: file, algorithm: .sha256)
        guard actual == expected else { throw Failure.mismatch(expected: expected, actual: actual) }
        return true
    }
}

extension UInt8 {
    fileprivate var isASCIIHexDigit: Bool {
        (0x30...0x39).contains(self) || (0x41...0x46).contains(self) || (0x61...0x66).contains(self)
    }
}
```

```swift
import SwiftUI
import UniformTypeIdentifiers

/// A Windows machine's installation media: an installer ISO from this Mac with an optional expected SHA-256, and an optional
/// driver disc. Both are local files chosen in the open panel; the app offers no download and no address field.
struct WindowsMediaSection: View {
    @Bindable var model: NewMachineModel

    @State private var target: Slot?

    private enum Slot: Identifiable {
        case installer, driverDisc
        var id: Self { self }
    }

    var body: some View {
        Section {
            fileRow("Installer ISO", path: model.localPath) { target = .installer }
            note(WindowsRequirements.installerNote)
            TextField("Expected SHA-256", text: $model.expectedSHA256, prompt: Text("Optional: 64 hexadecimal digits"))
                .font(.body.monospaced())
            if let problem = InstallerDigest.problem(in: model.expectedSHA256) {
                Label(problem.localizedDescription, systemImage: "exclamationmark.triangle").foregroundStyle(.orange)
            }
            note(WindowsRequirements.expectedSHA256Note)
            fileRow("Driver disc (optional)", path: model.driverDiscPath) { target = .driverDisc }
            if model.driverDiscPath != nil {
                Button("Remove Driver Disc", role: .destructive) { model.driverDiscPath = nil }
            }
            note(WindowsRequirements.driverDiscNote)
            if model.isVerifying {
                HStack {
                    ProgressView().controlSize(.small)
                    Text("Checking the installer…")
                }
            }
        } header: {
            HelpHeader("Windows installation media", topic: .guestSystems)
        }
        .fileImporter(
            isPresented: Binding(get: { target != nil }, set: { if !$0 { target = nil } }), allowedContentTypes: [.diskImage, .data]
        ) { [slot = target] result in
            guard let url = try? result.get() else { return }
            if slot == .driverDisc { model.chooseDriverDisc(url) } else { model.chooseLocalFile(url) }
        }
    }

    private func fileRow(_ title: String, path: String?, choose: @escaping () -> Void) -> some View {
        LabeledContent(title) {
            HStack {
```
