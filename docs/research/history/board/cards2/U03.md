## Why

ADR-0059 item 3 and CONTRIBUTING: anything that widens what the app does with the host must be reflected in the security profiles, the exposure summary, the managed preferences and the help, and be covered by a test. This card is the policy only. It decides whether a private interface may be used; it does not use one, and it makes no Windows machine (the guest kind is another card's). It exposes one pure function that the machine builder will call.

Judgement calls (recorded; do not change them):

1. **The posture is the profile the machine matches** (`VMConfig.detectedProfile`), or nil when its switches have been customized. Isolated and Hardened close private interfaces; Standard, Contained and a customized machine do not (profiles are presets over editable switches, ADR-0004). No setting of the machine changes: the decision is made when the machine starts.
2. **Order of reasons:** the organisation (managed key) first, then the profile, then the developer's kill switch, so a start error names the party that can change the outcome last.
3. **The managed key** is `AllowPrivateInterfaces`, one key for every private interface: forced to anything but `true` it denies (the repository's `Allow…` rule), `isLocked(_:)` covers it through its default case, and the managed-settings help topic lists it (an existing test requires that). It rewrites no machine (`clamp` is unchanged): there is no setting to rewrite.
4. **The kill switch** is a developer default in the app's defaults domain, `DisablePrivateInterfaces`, read once when a machine starts, like `CustomGPUInput`. Absent or an explicit false leaves private interfaces on; a value of any other type turns them off (fail closed).
5. **The exposure line** ranks `.low`: it is about the app's dependence on an undocumented switch, not about something the guest can reach. `VMConfig.privateCapabilities` names the interfaces a machine would use; the switch over `GuestOS` has no `default`, so adding a guest that needs one fails to compile until it names it.
6. **Help** gets one topic, *Private interfaces* (Security area), plus a bullet in *Settings your organisation manages*.

```swift
import Foundation
import PrivateInterfaces

/// Who may turn a private interface on: the machine's security profile, the organisation's managed preferences and a developer's
/// kill switch (ADR-0019, ADR-0059). The decision is made before the capability module is asked anything, so a closed profile or a
/// managed refusal never reaches the framework.
enum PrivateCapabilityPolicy {
    /// The managed key that turns every private interface off for the organisation's Macs.
    static let managedKey = ManagedKey.allowPrivateInterfaces

    enum Decision: Equatable, Sendable {
        case allowed
        case denied(Reason)

        var isAllowed: Bool { self == .allowed }
    }

    /// Why a private interface is off, in the order the policy looks: the organisation first, then the profile, then the kill switch.
    enum Reason: Equatable, Sendable, CustomStringConvertible {
        case managedKey
        case profile(SecurityProfile)
        case killSwitch

        var description: String {
            switch self {
            case .managedKey:
                "your organisation turned private interfaces off (\(ManagedKey.allowPrivateInterfaces.rawValue))"
            case .profile(let profile):
                "this machine uses the \(profile.label) profile, which closes private interfaces"
            case .killSwitch:
                "the developer default \(PrivateInterfacesKillSwitch.defaultsKey) is on"
            }
        }
    }

    /// The profiles that close every private interface.
    static let closingProfiles: Set<SecurityProfile> = [.isolated, .hardened]

    /// `posture` is the profile the machine matches (`VMConfig.detectedProfile`), or nil when its switches have been customized,
    /// which no profile closes. A refusal by the organisation outranks the profile, and the profile outranks the kill switch, so
    /// the reason names the party that can change the outcome last.
    static func decide(posture: SecurityProfile?, managed: ManagedPreferences, killSwitch: Bool) -> Decision {
        if managed.isLocked(managedKey) { return .denied(.managedKey) }
        if let posture, closingProfiles.contains(posture) { return .denied(.profile(posture)) }
        if killSwitch { return .denied(.killSwitch) }
        return .allowed
    }

    /// What the exposure summary says about a private interface a machine would use.
    static func exposure(for capability: PrivateCapabilityID) -> Exposure {
        Exposure(
            level: .low,
            text: "Private interface: \(capability.title). The app uses a framework switch Apple does not document; "
                + "it can stop working with a macOS update.")
    }
}

/// A developer's kill switch for every private interface, in the app's defaults domain: `defaults write <the app's bundle
/// identifier> DisablePrivateInterfaces -bool true`. It is read once when a machine starts, not a setting in the app. Only an
/// absent key or an explicit false leaves the interfaces on; a value of any other type turns them off.
enum PrivateInterfacesKillSwitch {
    static let defaultsKey = "DisablePrivateInterfaces"

    static func isOn(in defaults: UserDefaults = PreferencesDomain.defaults) -> Bool {
        guard let stored = defaults.object(forKey: defaultsKey) else { return false }
        return (stored as? Bool) != false
    }
}

extension VMConfig {
    /// The private interfaces this machine's start would use, each listed in its exposure summary. The guests the app builds
    /// today use none; a guest that needs one names it here, and the switch fails to compile until it does.
    var privateCapabilities: [PrivateCapabilityID] {
        switch guest {
        case .macOS, .linux: []
        }
    }
}
```

```swift
        let values: [String: Any]
        let denies: Bool

        ManagedPreferences(forcedValue: { values[$0] })

    @Test
    func everyPostureManagedValueAndKillSwitchGivesTheExpectedDecision() {
        var checked = 0
        for posture in Self.postures {
            for managed in Self.managedCases {
                for killSwitch in [false, true] {
                    let decision = PrivateCapabilityPolicy.decide(
                        posture: posture, managed: forced(managed.values), killSwitch: killSwitch)
                    let label = "\(String(describing: posture)) / \(managed.label) / kill switch \(killSwitch)"
                    let profileCloses = posture.map { Self.closed.contains($0) } ?? false
                    if managed.denies {
                        #expect(decision == .denied(.managedKey), "\(label)")
                    } else if profileCloses, let posture {
                        #expect(decision == .denied(.profile(posture)), "\(label)")
                    } else if killSwitch {
                        #expect(decision == .denied(.killSwitch), "\(label)")
                    } else {
                        #expect(decision == .allowed, "\(label)")
                    }
                    #expect(decision.isAllowed == (decision == .allowed), "\(label)")
                    checked += 1
                }
            }
        }

    }
```
