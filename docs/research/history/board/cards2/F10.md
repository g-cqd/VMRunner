# F10 — Only a locked control gets the lock row; a disk serial number keeps printable ASCII only

Model: haiku · Effort: low · Worktree: yes, `WT = ~/Developer/g-cqd/VMRunner-chains/f-followups` (branch `chain/f-followups`) · Chain: F, card 10 of 12 (after F09; next F11)

Anchors: locate every edit by its text (`grep -nF`), never by a line number. Verified on `main` at `a98fd14`.

Why (read from the code):

1. `View.lockedByOrganisation(_:)` in `Views/ManagedLock.swift` wraps every control it is applied to (twelve call sites) in an
   `HStack`, also when nothing is locked, which can change how a form lays the row out. After this card an unlocked control is
   returned as it is; a locked one gets the row with the lock icon, its tooltip and its accessibility label, as before.
2. `IdentitySection.serial` keeps any ASCII character, so a tab, a newline or another control character reaches
   `VMConfig.diskSerial`, and from there the disk's identifier. After this card the editor keeps only printable ASCII without
   spaces, `!` to `~` (0x21 to 0x7E), still at most `EditorLimits.maxDiskSerialLength` characters. The filter is a
   `nonisolated static` function so a test can call it.

```swift
    /// The serial number as typed, kept to what a stored configuration may hold: ASCII, at most 20 characters.
    private var serial: Binding<String> {
        Binding(
            get: { config.diskSerial },
            set: { config.diskSerial = String($0.filter(\.isASCII).prefix(EditorLimits.maxDiskSerialLength)) })
    }
```

   with

```swift
    /// The serial number as typed, kept to what a disk identifier may hold (`serialNumber(typed:)`).
    private var serial: Binding<String> {
        Binding(get: { config.diskSerial }, set: { config.diskSerial = Self.serialNumber(typed: $0) })
    }

    /// `typed` with only printable ASCII without spaces (`!` to `~`), cut to `EditorLimits.maxDiskSerialLength` characters:
    /// no space, tab, newline or other control character reaches the disk's identifier.
    nonisolated static func serialNumber(typed: String) -> String {
        String(typed.filter { (0x21...0x7E).contains($0.asciiValue ?? 0) }.prefix(EditorLimits.maxDiskSerialLength))
    }
```
