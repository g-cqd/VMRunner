## The local control service, first step

Eleven commits build the control service of roadmap 0005 as ADR-0056 (proposed) decides; each passed `swift run vmr check`.
Scripts and AI agents can list machines, read their state, and start and stop them, over one private local socket, with a
token that grants only what it names, and only on machines that allow it. Nothing here was run in the app, with a real client
or with a real machine: every claim below comes from tests.

| # | Claim | Probe | Verdict |
|---|---|---|---|
| 1 | A request line is parsed strictly; a batch is refused with -32600 and a notification is neither run nor answered | unit tests of the library | TESTED |
| 2 | A token's secret is 256 random bits, never written to disk; its SHA-256 digest is compared in constant time | unit tests; reading the code (no early exit) | TESTED; constant time by construction |
| 3 | Each method needs its capability; a revoked token fails at once; a machine outside the token's or with access off is refused | dispatcher tests | TESTED |
| 4 | A client of another user is closed before anything is read, and reported | end-to-end test with the user check injected | TESTED |
| 5 | A request over 64 KiB is answered -32600 and closed, a silent client is closed, a slow answer is -32005, a client that stops reading is dropped | end-to-end tests over socket pairs and a socket under `/tmp` | TESTED |
| 6 | The socket is 0600 in a 0700 folder; a too-long path, an open folder and a client past the limit are refused | listener and service tests under `/tmp` | TESTED |
| 7 | Isolated and Hardened turn agent access off; the exposure summary names it | model tests | TESTED |
| 8 | A line nested too deeply is refused unparsed, and a connection open when the service is turned off gets no more answers | unit and socket tests | TESTED |
| 9 | The service runs in the app and starts a real machine for a real client | the owner's run | NOT RUN |

### What was built

- A library target, `ControlProtocol`, linked by the app: messages, tokens and their store, the checks, the connection,
  the listener and a small client. It uses the console's socket code, now shared within the package.
- In the app: the Settings switch (off by default), the managed key `AllowControlService`, the per-machine agent access
  switch (off by default, off in the closed profiles, in the exposure summary), the token list in Settings, three help
  topics, and refusals logged without the token. Start, suspend and stop can now be awaited; the menus use the same path.

### Decisions to confirm

The defaults the owner may change are listed with ADR-0056: one request per line; the token in every request; notifications
ignored; a clean stop answers at once; the limits (64 KiB, 4 clients, 64 requests, 10 s, 2 s, 120 s, 32 tokens); the
folder `Control` in the data folder with no fallback when its path is too long; an agent's start never prompts; the
exposure level low; the library's API public, like the console's.

The owner's run (roadmap 0005, item 1), then the command-line client and the MCP server over stdio.
