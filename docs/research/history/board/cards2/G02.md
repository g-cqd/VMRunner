Why (found by an authorised real-guest run on 2026-10-22): the kill switch cut and gave back the network card as designed,
but nothing in the log said so; the only evidence was the toolbar icon, so the behaviour could not be checked without a
screen. After this card `NetworkCutoff.apply(_:)`, which decides each change and knows its reason, logs one public line per
change: a cut with its reason, a reconnection with the reason that ended, a cut that stays for another reason. The line names
the rule only (`vpnRequired`, `vpnForbidden`, `meteredPath`): no address, interface or network name, so it is `.public` like
the app's other enum-only lines. A cut the card refuses is already logged by F08 (`The network card stayed connected after
the kill switch cut it; stopping the machine`), so `setNetworkConnected` gets no second line.

The doc comment F08 wrote is right about the read-back; this card adds what really happens to a disconnection the framework
makes on its own: `VZGuestMachine` does not implement the delegate's
`virtualMachine(_:networkDevice:attachmentWasDisconnectedWithError:)` (the framework calls it "when an error causes a VM's
network attachment to disconnect"), so such a disconnection is neither logged nor shown. (The review text said a refused
change "is reported to the delegate"; F08 already removed that wording.)

Testability: a log line cannot be read back in a unit test. The text and the decision that feeds it are a static function,
`NetworkCutoff.logLine(from:to:)`, which `apply` calls; the test checks its four cases. That `apply` calls it is not
unit-tested (it is one line, read in review).

```swift
    /// What the log says when the reason changes from `old` to `new`: a cut with its reason, a reconnection with the
    /// reason that ended, or a cut that stays for another reason. It names the rule only: no address, interface or network
    /// name, so it is public.
    static func logLine(from old: NetworkCutoffReason?, to new: NetworkCutoffReason?) -> String? {
        switch (old, new) {
        case (nil, let cut?): "Kill switch: cutting the network card (\(cut))"
        case (let ended?, nil): "Kill switch: reconnecting the network card (\(ended) no longer holds)"
        case (let was?, let now?) where was != now: "Kill switch: the network card stays cut (\(was), now \(now))"
        default: nil
        }
    }
```
