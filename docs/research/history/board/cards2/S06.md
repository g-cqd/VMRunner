Why: a container machine runs by spawning the container runner (the signed helper that boots the container) with `--json` and following its output. This card is the part of that which needs no screen and no factory: the exact command line, the decoding of the runner's event lines, a log that keeps at most 1 MiB of what the untrusted container printed (after the console filter), and the driver that owns the child process: it stops it by the protocol, escalates when the runner does not obey, and never leaks a descriptor. The driver was reviewed and revised in place; "Fixed after review" below lists what the review changed. Nothing uses it yet; the next card wires it into a workload and the factory. Decisions:
- **Command line** (`ContainerRunnerArguments.make(for:scratch:)`): `<scratch> --json --image <image> --cpus <n> --memory <MiB> --network <none|loopback>`, then `--env NAME=value` per environment entry in the spec's order, then `--command <element>` per command element (so an element that starts with a dash is still one value). The spec was checked by `VMConfig.validate()`, so the line is one the runner accepts; the runner checks again.
- **Runner environment** (`minimalEnvironment(from:)`): only `PATH` (default `/usr/bin:/bin`), `HOME` and `TMPDIR` of the app. No `DYLD_*`, no proxy or credential variable. The container's own variables travel as `--env` arguments, never in the process environment.
- **Scratch folder**: `ContainerScratch.prepare(_:)` is here, for the next card to call before it starts a runner: it creates the folder (with its parents) with permissions 0700, makes an existing one 0700, and refuses a symbolic link or a file in its place. Cleaning it up is NOT automatic and nothing here removes it: it holds the kernel and the image the runner downloaded, so the next run starts fast. Deleting a machine removes it with the machine's folder.
- **Event lines**: `ContainerEvent(line:)` decodes the five kinds (`phase`, `output`, `exited`, `error`, `finished`) and returns nil for a line that is not a JSON object, a kind it does not know, or a line that lacks a field its kind needs. `RunnerLineSplitter` cuts the byte stream into lines whatever the size of the reads (a partial line is held), skips empty lines, and drops a line longer than its bound whole (to its newline), counting it. The bound is 256 KiB, not 64 KiB: the runner's longest legitimate line is an `output` event of 16384 bytes of control characters, each escaped to six bytes in JSON (just under 100 KiB), so 64 KiB would drop real output. The bound is a parameter, so the tests use a small one.
- **Log** (`ContainerLog`, `@MainActor @Observable`, so a view can observe it): `output` keeps the container's output in a `BoundedText` (default 1 MiB, oldest bytes dropped at a character boundary, the count kept; `markedText` leads with `[dropped N bytes]`). A full text is cut by the excess plus a quarter of the limit, so the copy happens once per quarter of the limit appended and not on every append. Every output chunk passes through `ConsoleOutputFilter`, with one filter per stream (stdout, stderr) because the filter carries a cut sequence from one call to the next. The runner's phases, the container's exit status, the runner's reported status and its errors are kept as values, not mixed into the text (the errors are filtered, at most 16, at most 1024 characters each; the phases are at most 16, each name filtered and cut to 64 characters). The runner's own standard error is `diagnostics`, filtered and bounded to 64 KiB. Lines that were not events are counted (`ignoredLines`), and lines dropped for their length (`droppedLines`).
- **Driver** (`ContainerProcess`, `@MainActor`): `start()` opens the three pipes itself with `pipe(2)` (`RunnerPipes`: six descriptors, every one `FD_CLOEXEC`), gives the child its three ends through Foundation `Process`, and keeps the other three: the input's write end (inside the `RunnerHandle`) and the two read ends, each owned by a `PipeReader`. A `PipeReader` follows its descriptor with a dispatch read source: the event handler does one `read(2)` of at most 64 KiB (EINTR and EAGAIN return, a read of 0 is the end and cancels the source, anything else is data) and the cancel handler closes the descriptor; dispatch runs the cancel handler after the last event handler returned, so a read never meets a closed descriptor. (A file handle's `readabilityHandler` can run once more after its handle was closed, and `availableData` then raises an exception; that crash was in the first version.) Everything the readers and the termination handler report is yielded in order into one `AsyncStream`, and one main-actor task applies it, so the log gets the events in order and the end is reported once (`onExit`, `waitForExit()`), only after the process ended AND both outputs reached their end AND both readers closed their descriptors. If an output never ends (a descendant of the runner kept the pipe), the end is reported `Timing.drainGrace` (2 s, injected clock) after the process ended, and the readers are cancelled; while output that was read still waits to be applied the wait starts again, at most 5 times. `onEvent` reports each decoded event after the log has it (the next card uses it to see that the container runs). The parent closes its copies of the child's three ends right after the spawn; the stdin write end is closed by the stop or at the end. Nothing is left open on any path, including a refused start: a `DescriptorLedger` counts the run's descriptors as they open and close, and `openDescriptorCount` is 0 before the start and after the end (the tests read it; counting `/dev/fd` sees the files other suites open meanwhile). A `ContainerProcess` released while its runner still runs (`isolated deinit`) kills the runner, closes the descriptors and leaves the registry. `waitForExit()` on a process that was never started, or whose start threw, returns `ContainerExit.notStarted` (status -1) at once and does not wait.
- **Stop**: `stop()` writes `stop\n` to the runner's standard input and closes it. The write end is non-blocking (`O_NONBLOCK`) and has `F_SETNOSIGPIPE`, so a runner that never reads cannot block the app and a runner that is already gone cannot kill the app with SIGPIPE. A runner alive after `Timing.stopGrace` (10 s) gets SIGTERM, and after `Timing.terminateGrace` (5 s) more SIGKILL; all three waits use the injected clock (`any Clock<Duration>`, a `TestClock` in the tests). `kill()` is SIGKILL at once. Both are idempotent and do nothing after the end. The end of the runner's standard input (the app died) is also a stop for the runner; a test pins that the child does not inherit the write end. The signal goes to the pid after a check that the runner still runs; the pid could in principle be reused between the two, which macOS's sequential pids and Foundation's prompt reaping make not happen in practice (a comment says so).
- **Quit** (`ContainerProcesses.shared`, `terminateAll(timeout:killWait:)`): every started runner is in the registry until its end. `terminateAll` is synchronous and does not need the main actor: it writes the stop line to each, polls until they end or `timeout` (default 5 s), kills the ones still running, and polls up to `killWait` (default 1 s) for the system to report it. The registry holds a `RunnerHandle` (the process and the stdin write end behind a lock), not the driver. `ContainerProcess` takes the registry as a parameter (default `.shared`) so tests never touch each other's runners.
- **Backpressure** (`OutputBacklog`): the readers hand data to the main actor through the stream, and a shared byte budget (a `Mutex`) counts what is queued and not yet applied. A reader that finds more than 4 MiB queued suspends its source; the main-actor consumer subtracts the bytes after it applied them and resumes the readers when less than 1 MiB is left. A runner that writes faster than the app applies is then held back by its full pipe. The stream is not made `bufferingNewest`: that would drop the `ended` and `terminated` reports with the data. A suspended source must be resumed before it is cancelled, so the budget is closed (it resumes every paused reader and pauses none again) before the readers are cancelled, and suspending and resuming happen under the budget's lock so a reader is never resumed before it was paused.
- **Deadwood**: the gate's dead-code analyzer reports a member only tests reach; seven members carry a trailing `// @dw:accept:this referenced-only-by-tests -- <reason>` (`BoundedText.markedText`, `ContainerScratch`, `ContainerExit.notStarted`, `ContainerProcess.waitForExit()`, `ContainerProcess.openDescriptorCount`, `ContainerProcesses.liveCount`, `ContainerProcesses.terminateAll`). The next card removes the directive of each member it calls (all but `openDescriptorCount` and `liveCount`, which only tests read).
- **Not done here, on purpose**: the workload, the factory, the quit hook and the log view (the next cards).
- **Fixed after review**: (1) a crash: the readers were file handles with a `readabilityHandler`, which can run after the handle is closed (when the drain wait ran out); they are now dispatch sources on descriptors the driver owns, as described under Driver. (2) The stream from the readers to the main actor was unbounded; it now has the byte budget described under Backpressure, and the drain wait starts again while output is backlogged. (3) `BoundedText.append` copied the whole text on every append once it was full; it now cuts a quarter of the limit more than the excess. This is a deliberate change of this card's own behaviour, so the expected `droppedBytes` in `ContainerParsingTests` changed with it (limit 10 and 13 bytes now drops 5, not 3; a 4-byte limit and 10 bytes keeps `789`, not `6789`); no test was weakened, and a new test pins the cut once per quarter. (4) The descriptor test compared the `/dev/fd` pipe count and flaked when suites ran in parallel; it reads the driver's own `openDescriptorCount`. (5) The test that holds a pipe open used `sleep 3 &`, which outlived the test; it uses `sleep 60 & echo $! > "$0.pid"; exit 0` and the test kills that pid when it is done. (6) The polite runner of the quit test had 500 ms to honour the stop, which a loaded machine can miss; it has 2 s. (7) `phases` was unbounded; it is bounded to 16 entries of 64 characters. Also: every pipe descriptor is `FD_CLOEXEC`, the event decoder is a `static let`, a comment explains the pid race of the signals, a process released mid-run kills its runner, and `waitForExit()` on a process that never started returns `ContainerExit.notStarted`.

```swift
import Foundation

/// The command line of the container runner for one container machine. The runner checks every value again; the spec was
/// checked by `VMConfig.validate()`, so a line built here is one it accepts.
enum ContainerRunnerArguments {
    /// `<scratch> --json --image <reference> --cpus <n> --memory <MiB> --network <none|loopback>`, then one `--env NAME=value`
    /// per environment entry in the spec's order and one `--command <element>` per command element. The command is not run
    /// through a shell, and an element that starts with a dash is still one value of `--command`.
    static func make(for spec: ContainerSpec, scratch: URL) -> [String] {
        var arguments = [
            scratch.path, "--json", "--image", spec.image, "--cpus", String(spec.cpus), "--memory", String(spec.memoryMiB),
            "--network", spec.network.rawValue,
        ]
        for entry in spec.environment {
            arguments += ["--env", "\(entry.name)=\(entry.value)"]
        }
        for element in spec.command {
            arguments += ["--command", element]
        }
        return arguments
    }

    /// What a runner inherits from the app: the search path, the home folder and the temporary folder, and nothing else (no
    /// `DYLD_*` variable, no proxy or credential variable). The container's own environment travels as `--env` arguments.
    static func minimalEnvironment(from source: [String: String]) -> [String: String] {
        var environment = ["PATH": source["PATH"] ?? "/usr/bin:/bin"]
        for name in ["HOME", "TMPDIR"] {
            if let value = source[name] { environment[name] = value }
        }
        return environment
    }
}

/// The folder a runner works in: it holds the kernel and the image cache it downloads, so it outlives a run and nothing here
/// removes it.
enum ContainerScratch {  // @dw:accept:this referenced-only-by-tests -- the machine start prepares the folder with it
    struct Refusal: LocalizedError, Equatable {
        let path: String
        var errorDescription: String? { "The container's working folder \(path) is not a folder of its own (a link or a file)." }
    }

    /// Creates the folder with permissions 0700, with its parents as needed, and makes an existing one 0700. A link or a
    /// file in its place is refused: the runner would write through it.
    static func prepare(_ url: URL) throws {
        let manager = FileManager.default
        if let type = try? manager.attributesOfItem(atPath: url.path)[.type] as? FileAttributeType, type != .typeDirectory {
            throw Refusal(path: url.path)
        }
        try manager.createDirectory(at: url, withIntermediateDirectories: true, attributes: [.posixPermissions: 0o700])
        try manager.setAttributes([.posixPermissions: 0o700], ofItemAtPath: url.path)
    }
}
```

```swift
import Foundation

/// Which output stream of the container a chunk came from.
enum ContainerStream: String, Sendable {
    case stdout, stderr
}

/// One line the runner wrote to its standard output in `--json` mode, decoded. A line of an unknown kind, a line that is not a
/// JSON object, and a line that lacks what its kind needs decode to nothing: a newer runner may say more than this app knows.
enum ContainerEvent: Equatable, Sendable {
    case phase(name: String, seconds: Double)
    case output(stream: ContainerStream, text: String)
    case exited(status: Int32)
    case error(message: String)
    case finished(status: Int32)

    /// The fields of a line; each kind uses some of them.
    private struct Wire: Decodable {
        var event: String
        var name: String?
        var seconds: Double?
        var stream: String?
        var text: String?
        var status: Int32?
        var message: String?
    }

    private static let decoder = JSONDecoder()

    /// The event in `line` (without its newline), or nil.
    init?(line: some Collection<UInt8>) {
        guard let wire = try? Self.decoder.decode(Wire.self, from: Data(line)) else { return nil }
        switch wire.event {
        case "phase":
            guard let name = wire.name else { return nil }
            self = .phase(name: name, seconds: wire.seconds ?? 0)
        case "output":
            guard let stream = wire.stream.flatMap(ContainerStream.init(rawValue:)), let text = wire.text else { return nil }
            self = .output(stream: stream, text: text)
        case "exited":
            guard let status = wire.status else { return nil }
            self = .exited(status: status)
        case "error":
            guard let message = wire.message else { return nil }
            self = .error(message: message)
        case "finished":
            guard let status = wire.status else { return nil }
            self = .finished(status: status)
        default:
            return nil
        }
    }
}

/// Cuts the bytes the runner writes into lines, whatever the size of the reads: a line held back until its newline arrives
/// may span reads. A line longer than `maxLineBytes` is dropped whole (up to its newline) and counted, so the buffer stays
/// small whatever the runner writes. The runner's longest legitimate line is an `output` event of 16384 bytes of control
/// characters, each escaped to six, which is under 100 KiB; the default bound leaves room for that.
struct RunnerLineSplitter: Sendable {
    static let defaultMaxLineBytes = 256 * 1024

    let maxLineBytes: Int
    /// How many lines were dropped for their length.
    private(set) var droppedLines = 0
    private var pending: [UInt8] = []
    /// Whether the rest of the current line is skipped because it was too long.
    private var skipping = false

    init(maxLineBytes: Int = Self.defaultMaxLineBytes) {
        self.maxLineBytes = maxLineBytes
    }

    /// The complete lines the chunk finishes, without their newlines and in order; empty lines are skipped.
    mutating func append(_ chunk: [UInt8]) -> [[UInt8]] {
        var lines: [[UInt8]] = []
        var start = chunk.startIndex
        while let newline = chunk[start...].firstIndex(of: UInt8(ascii: "\n")) {
            take(chunk[start..<newline])
            endLine(into: &lines)
            start = newline + 1
        }
        take(chunk[start...])
        return lines
    }

    /// The end of the stream: the last line, when it had no newline.
    mutating func finish() -> [[UInt8]] {
        var lines: [[UInt8]] = []
        endLine(into: &lines)
        return lines
    }

    private mutating func take(_ segment: ArraySlice<UInt8>) {
        guard !skipping, !segment.isEmpty else { return }
        guard pending.count + segment.count <= maxLineBytes else {
            droppedLines += 1
            skipping = true
            pending = []
            return
        }
        pending += segment
    }

    private mutating func endLine(into lines: inout [[UInt8]]) {
        if !skipping, !pending.isEmpty { lines.append(pending) }
        pending = []
        skipping = false
    }
}
```

```swift
import GuestConsole
import Observation

/// Text kept to a size: when an append passes the limit the oldest bytes go, at a character boundary, and the count of what
/// went is kept. A quarter of the limit goes beyond the excess, so a text that is full is copied once per quarter of the limit
/// that was appended, not on every append.
struct BoundedText: Equatable, Sendable {
    let limit: Int
    private(set) var text = ""
    private(set) var droppedBytes = 0

    init(limit: Int) {
        self.limit = max(0, limit)
    }

    /// The text, led by a line that says how much of the start was dropped.
    var markedText: String {  // @dw:accept:this referenced-only-by-tests -- the log view shows it
        droppedBytes > 0 ? "[dropped \(droppedBytes) bytes]\n" + text : text
    }

    mutating func append(_ bytes: [UInt8]) {
        guard !bytes.isEmpty else { return }
        text += String(decoding: bytes, as: UTF8.self)  // swiftlint:disable:this optional_data_string_conversion
        guard text.utf8.count > limit else { return }
        let kept = Array(text.utf8)
        var cut = kept.count - limit + limit / 4
        while cut < kept.count, kept[cut] & 0xC0 == 0x80 { cut += 1 }
        droppedBytes += cut
        text = String(decoding: kept[cut...], as: UTF8.self)  // swiftlint:disable:this optional_data_string_conversion
    }
}

/// What a container run has said, for the log view: the container's output (bounded, and passed through the console filter
/// because the container is untrusted), the runner's phases, the container's and the runner's exit statuses and the errors the
/// runner reported, and the runner's own diagnostics from its standard error.
@MainActor @Observable
final class ContainerLog {
    static let defaultLimit = 1024 * 1024
    static let diagnosticsLimit = 64 * 1024
    static let maxErrors = 16
    static let maxErrorCharacters = 1024
    static let maxPhases = 16
    static let maxPhaseNameCharacters = 64

    /// A phase the runner finished and how long it took.
    struct Phase: Equatable, Sendable {
        let name: String
        let seconds: Double
    }

    /// The container's output, both streams in the order they arrived.
    private(set) var output: BoundedText
    /// What the runner wrote to its standard error.
    private(set) var diagnostics = BoundedText(limit: ContainerLog.diagnosticsLimit)
    private(set) var phases: [Phase] = []
    /// The container process's exit status, once it ended.
    private(set) var containerStatus: Int32?
    /// The runner's own exit status as it reported it in its last line.
    private(set) var finishedStatus: Int32?
    private(set) var errors: [String] = []
    /// Lines of the runner's output that were not an event this app knows.
    private(set) var ignoredLines = 0
    /// Lines of the runner's output dropped for their length.
    private(set) var droppedLines = 0

    @ObservationIgnored private var filters: [ContainerStream: ConsoleOutputFilter] = [:]
    @ObservationIgnored private var diagnosticsFilter = ConsoleOutputFilter()

    init(limit: Int = ContainerLog.defaultLimit) {
        output = BoundedText(limit: limit)
    }

    func apply(_ event: ContainerEvent) {
        switch event {
        case .phase(let name, let seconds):
            guard phases.count < Self.maxPhases else { return }
            phases.append(Phase(name: String(Self.plain(name).prefix(Self.maxPhaseNameCharacters)), seconds: seconds))
        case .output(let stream, let text):
            var filter = filters[stream] ?? ConsoleOutputFilter()
            output.append(filter.pass(Array(text.utf8)[...]))
            filters[stream] = filter
        case .exited(let status):
            containerStatus = status
        case .error(let message):
            guard errors.count < Self.maxErrors else { return }
            errors.append(String(Self.plain(message).prefix(Self.maxErrorCharacters)))
        case .finished(let status):
            finishedStatus = status
        }
    }

    /// What the runner wrote to its standard error.
    func appendDiagnostics(_ bytes: [UInt8]) {
        diagnostics.append(diagnosticsFilter.pass(bytes[...]))
    }

    func noteIgnoredLine() { ignoredLines += 1 }

    func noteDroppedLines(total: Int) { droppedLines = total }

    /// A runner's text with everything the console filter removes taken out.
    private static func plain(_ text: String) -> String {
        var filter = ConsoleOutputFilter()
        let bytes = filter.pass(Array(text.utf8)[...])
        return String(decoding: bytes, as: UTF8.self)  // swiftlint:disable:this optional_data_string_conversion
    }
}
```

```swift
import Darwin
import Foundation
import Synchronization

/// How many descriptors a run holds open: each end of each pipe is counted when it is opened and when it is closed. A test reads
/// it to see that a run leaves none behind; the system's own table cannot say that while other suites open files.
final class DescriptorLedger: Sendable {
    private let open = Mutex(0)

    var count: Int { open.withLock { $0 } }

    func opened(_ number: Int = 1) { open.withLock { $0 += number } }

    func closed() { open.withLock { $0 -= 1 } }

    /// Closes a descriptor this ledger counted.
    func close(_ descriptor: Int32) {
        _ = Darwin.close(descriptor)
        closed()
    }
}

/// The three pipes of one run: six ends, every one close-on-exec, so no other child this app starts inherits one. The runner
/// gets its three ends through the spawn's own descriptor setup. The driver closes its copies of the runner's ends as soon as
/// the runner has them, and keeps the other three: the write end of the input, and the two read ends it follows.
struct RunnerPipes {
    /// The write end of the runner's standard input.
    let input: FileHandle
    let inputRead: Int32
    let outputRead: Int32
    let outputWrite: Int32
    let errorRead: Int32
    let errorWrite: Int32
    let ledger: DescriptorLedger

    /// Opens the pipes; nil when the system refuses, with nothing left open.
    init?(ledger: DescriptorLedger) {
        guard let standardInput = Self.makePipe() else { return nil }
        guard let standardOutput = Self.makePipe() else {
            Self.discard(standardInput)
            return nil
        }
        guard let standardError = Self.makePipe() else {
            Self.discard(standardInput)
            Self.discard(standardOutput)
            return nil
        }
        input = FileHandle(fileDescriptor: standardInput.write, closeOnDealloc: true)
        inputRead = standardInput.read
        outputRead = standardOutput.read
        outputWrite = standardOutput.write
        errorRead = standardError.read
        errorWrite = standardError.write
        self.ledger = ledger
        ledger.opened(6)
    }

    /// Gives the process the runner's three ends as its standard streams. They stay owned by this value.
    func connect(_ process: Process) {
        process.standardInput = FileHandle(fileDescriptor: inputRead, closeOnDealloc: false)
        process.standardOutput = FileHandle(fileDescriptor: outputWrite, closeOnDealloc: false)
        process.standardError = FileHandle(fileDescriptor: errorWrite, closeOnDealloc: false)
    }

    /// Closes the ends the runner has its own copies of: left open they would keep the pipes open after the runner is gone.
    func closeChildEnds() {
        for descriptor in [inputRead, outputWrite, errorWrite] { ledger.close(descriptor) }
    }

    /// Closes the two read ends: for a run that did not start, before anything follows them.
    func closeReadEnds() {
        for descriptor in [outputRead, errorRead] { ledger.close(descriptor) }
    }

    /// Closes the write end of the input: for a run that did not start, before a handle took it over.
    func closeInput() {
        try? input.close()
        ledger.closed()
    }

    private static func makePipe() -> (read: Int32, write: Int32)? {
        var ends: [Int32] = [-1, -1]
        guard unsafe pipe(&ends) == 0 else { return nil }
        let pair = (read: ends[0], write: ends[1])

            return nil
```

```swift
import Darwin
import Dispatch
import Foundation
import Synchronization

/// Something that can be held back and let go again, in balance: a reader of a pipe.
protocol Pausable: AnyObject, Sendable {
    func pause()
    func resume()
}

/// How many bytes the readers have queued for the main actor and it has not applied yet. A reader that finds more than
/// `pauseAbove` queued is paused, so a runner that writes faster than the app applies is held back by its full pipe instead of
/// filling memory; the consumer lets the readers go when `resumeBelow` is reached. Pausing and resuming happen under the lock,
/// so a reader is never resumed before it was paused, and a closed backlog pauses nothing: a paused source must be resumed
/// before it is cancelled.
final class OutputBacklog: Sendable {
    static let pauseAbove = 4 * 1024 * 1024
    static let resumeBelow = 1024 * 1024

    private struct State {
        var queued = 0
        var paused: [any Pausable] = []
        var closed = false
    }

    private let state = Mutex(State())

    /// The bytes queued and not applied yet.
    var queuedBytes: Int { state.withLock { $0.queued } }

    /// Counts `count` bytes `reader` is about to queue; pauses it when too much is queued.
    func queued(_ count: Int, from reader: some Pausable) {
        state.withLock { state in
            state.queued += count
            guard !state.closed, state.queued > Self.pauseAbove, !state.paused.contains(where: { $0 === reader }) else { return }
            reader.pause()
            state.paused.append(reader)
        }
    }

    /// Counts `count` queued bytes as applied; lets the readers go when little is left.
    func applied(_ count: Int) {
        guard count > 0 else { return }
        state.withLock { state in
            state.queued -= count
            guard state.queued < Self.resumeBelow else { return }
            Self.releasePaused(&state)
        }
    }

    /// Lets every paused reader go and pauses none again.
    func close() {
        state.withLock { state in
            state.closed = true
            Self.releasePaused(&state)
        }
    }

    private static func releasePaused(_ state: inout State) {
        for reader in state.paused { reader.resume() }
        state.paused = []
    }
}

/// What a ``PipeReader`` reports, in order.
enum PipeReport: Sendable {
    case data([UInt8])
    /// The write side closed and everything was read.
    case ended
    /// The descriptor is closed.
    case closed
}

/// A read end of a pipe the driver owns, followed with a dispatch source. The source's cancel handler closes the descriptor,
/// and dispatch runs it after the last event handler returned, so a read never meets a closed descriptor. (A file handle's
/// readability handler can run once more after the handle was closed, and reading then raises an exception.)
final class PipeReader: Pausable {
    private static let readSize = 64 * 1024

    private enum Chunk {
        case data([UInt8])
        case end
        case retry
    }

    private let source: any DispatchSourceRead

    private init(source: any DispatchSourceRead) {
        self.source = source
    }

    /// Starts following `descriptor`, which the reader owns from now on. A chunk is counted in `backlog` before it is reported.
    /// `report` is called from the reader's own queue.
    static func follow(
        _ descriptor: Int32, backlog: OutputBacklog, ledger: DescriptorLedger, report: @escaping @Sendable (PipeReport) -> Void
    ) -> PipeReader {
        // A read source needs a queue to run its handlers on.
        let queue = DispatchQueue(label: "container-runner-output", qos: .utility)  // swiftlint:disable:this no_dispatch_queue
        let source = DispatchSource.makeReadSource(fileDescriptor: descriptor, queue: queue)
        let reader = PipeReader(source: source)
        source.setEventHandler {
            switch Self.readChunk(from: descriptor) {
            case .retry:
                return
            case .data(let bytes):
                backlog.queued(bytes.count, from: reader)
                report(.data(bytes))
            case .end:
                report(.ended)
                reader.cancel()
            }
        }
        source.setCancelHandler {
            _ = Darwin.close(descriptor)
            ledger.closed()
            report(.closed)
        }
        source.activate()
        return reader
    }

    func pause() { source.suspend() }

    func resume() { source.resume() }

    /// Stops following and closes the descriptor once the running handler is done. A paused reader must be resumed first.
    func cancel() { source.cancel() }

    /// One read of what is there; the source says the descriptor is readable, so it does not wait.
    private static func readChunk(from descriptor: Int32) -> Chunk {
        withUnsafeTemporaryAllocation(byteCount: readSize, alignment: 1) { buffer in
            let count = unsafe read(descriptor, buffer.baseAddress, buffer.count)
            if count > 0 { return .data(unsafe Array(UnsafeRawBufferPointer(rebasing: buffer[..<count]))) }
            if count == 0 { return .end }
            return errno == EINTR || errno == EAGAIN ? .retry : .end
        }
    }
}
```

```swift
import Foundation

/// The parts of one runner process that can be reached from any thread: the stop request, the signals and the question
/// whether it still runs. The registry holds one per live runner so the app can end them when it quits, even while the main
/// actor is busy ending the app.
final class RunnerHandle: Sendable {
    let process: Process
    /// The write end of the runner's standard input, until it is closed. Non-blocking, and a write to a runner that is gone
    /// returns an error instead of raising SIGPIPE.
    private let stdin: Mutex<FileHandle?>
    private let ledger: DescriptorLedger

    /// Makes `stdin` non-blocking: the runner may never read it, and a full pipe must not block the app. Closing it is counted in
    /// `ledger`.
    init?(process: Process, stdin: FileHandle, ledger: DescriptorLedger = DescriptorLedger()) {
        let flags = fcntl(stdin.fileDescriptor, F_GETFL)
        guard flags >= 0, fcntl(stdin.fileDescriptor, F_SETFL, flags | O_NONBLOCK) == 0,
            fcntl(stdin.fileDescriptor, F_SETNOSIGPIPE, 1) == 0
        else { return nil }
        self.process = process
        self.stdin = Mutex(stdin)
        self.ledger = ledger
    }

    var isRunning: Bool { process.isRunning }

    /// Writes the `stop` line and closes the runner's standard input. A second call does nothing.
    func requestStop() {
        stdin.withLock { handle in
            guard let open = handle else { return }
            handle = nil
            let line = Array("stop\n".utf8)
            _ = line.withUnsafeBytes { unsafe write(open.fileDescriptor, $0.baseAddress, $0.count) }
            try? open.close()
            ledger.closed()
        }
    }

    /// Closes the runner's standard input without a request: the runner reads the end as a request to stop.
    func closeStdin() {
        stdin.withLock { handle in
            guard let open = handle else { return }
            handle = nil
            try? open.close()
            ledger.closed()
        }
    }

    /// SIGTERM, when the runner still runs. The check and the signal are two steps and Foundation reaps the child on its own, so
    /// the pid could in principle be reused in between. macOS hands out pids in sequence and wraps only after a full cycle, so a
    /// reuse within these few instructions does not happen in practice; the same goes for `forceKill()`.
    func terminate() {
        if process.isRunning { process.terminate() }
    }

    /// SIGKILL, when the runner still runs.
    func forceKill() {
        if process.isRunning { _ = Foundation.kill(process.processIdentifier, SIGKILL) }
    }
}

/// Every container runner that is running, in this process. The app ends them when it quits: a runner also ends by itself when
/// the end of its standard input arrives, but that needs this process to have closed it, and a crash leaves it to the system.
final class ContainerProcesses: Sendable {
    static let shared = ContainerProcesses()

    private let live = Mutex<[ObjectIdentifier: RunnerHandle]>([:])

    var liveCount: Int { live.withLock { $0.count } }  // @dw:accept:this referenced-only-by-tests -- a test reads it

    func register(_ handle: RunnerHandle) {
        live.withLock { $0[ObjectIdentifier(handle)] = handle }
    }

    func unregister(_ handle: RunnerHandle) {
        live.withLock { _ = $0.removeValue(forKey: ObjectIdentifier(handle)) }
    }

    /// Asks every live runner to stop, waits up to `timeout` for them to end, then kills the ones still running and waits up
    /// to `killWait` for the system to report it. Blocks the calling thread for at most `timeout + killWait`, and does not need
    /// the main actor, so the app can call it from `applicationWillTerminate`.
    func terminateAll(  // @dw:accept:this referenced-only-by-tests -- called at app quit
        timeout: Duration = .seconds(5), killWait: Duration = .seconds(1)
    ) {
        let handles = live.withLock { Array($0.values) }
        for handle in handles { handle.requestStop() }
        Self.wait(until: handles, within: timeout)
        for handle in handles { handle.forceKill() }
        Self.wait(until: handles, within: killWait)
    }

    private static func wait(until handles: [RunnerHandle], within limit: Duration) {
        let deadline = ContinuousClock.now + limit
        while handles.contains(where: \.isRunning), ContinuousClock.now < deadline {
            usleep(5000)
        }
    }
}
```

```swift
import Foundation

/// How a runner process ended.
struct ContainerExit: Equatable, Sendable {
    /// The exit status, or the signal number when `signaled`.
    let status: Int32
    let signaled: Bool

    /// What `waitForExit()` returns for a process that was never started: no runner ran, so there is no status.
    static let notStarted = Self(status: -1, signaled: false)  // @dw:accept:this referenced-only-by-tests -- waitForExit returns it
}

/// Why a runner did not start.
struct ContainerProcessError: LocalizedError, Equatable {
    let reason: String
    var errorDescription: String? { reason }
}

/// Runs one container runner as a child process and follows it: its event lines go into a ``ContainerLog`` in order, its
/// standard error becomes the log's diagnostics, and the process's end is reported once, after the last of its output.
///
/// Stopping is a request first: `stop()` writes `stop` to the runner's standard input and closes it; a runner still alive after
/// `Timing.stopGrace` gets SIGTERM, and after `Timing.terminateGrace` more SIGKILL. `kill()` is SIGKILL at once. The waits use
/// the injected clock. The process is in ``ContainerProcesses`` while it runs, and every descriptor this class opened is
/// closed when the run ends. The scratch folder is not touched: it holds the downloaded kernel and image cache.
///
/// The output is read off the main actor, by dispatch sources on descriptors this class owns, and queued for the main actor
/// with a byte budget: readers pause above 4 MiB queued and go on below 1 MiB. A process released while its runner still runs
/// kills the runner and closes everything.
@MainActor
final class ContainerProcess {
    struct Timing: Sendable {
        /// How long a requested stop may take before SIGTERM.
        var stopGrace = Duration.seconds(10)
        /// How long SIGTERM may take before SIGKILL.
        var terminateGrace = Duration.seconds(5)
        /// How long the output may take to end after the process did, before it is given up (a descendant that kept the
        /// pipe open would hold it forever).
        var drainGrace = Duration.seconds(2)
    }

    /// How many times the drain wait starts again while output that was read is still waiting to be applied.
    private static let maxDrainRearms = 5

    private enum Input: Sendable {
        case stdout([UInt8])
        case stderr([UInt8])
        case stdoutEnded, stderrEnded
        case readerClosed
        case terminated(ContainerExit)
        case drainExpired

        /// The bytes this report counts in the backlog.
        var byteCount: Int {
            switch self {
            case .stdout(let bytes), .stderr(let bytes): bytes.count
            default: 0
            }
        }
    }

    let log: ContainerLog
    /// Set once, when the run ended and all its output was applied to the log.
    private(set) var exit: ContainerExit?
    /// Called for each event the runner reported, in order, after the log has it.
    var onEvent: (@MainActor (ContainerEvent) -> Void)?
    /// Called once with the exit, on the main actor, after the log has everything.
    var onExit: (@MainActor (ContainerExit) -> Void)?

    private let executable: URL
    private let arguments: [String]
    private let environment: [String: String]
    private let clock: any Clock<Duration>
    private let timing: Timing
    private let registry: ContainerProcesses
    private let backlog: OutputBacklog
    private let ledger = DescriptorLedger()

    private var handle: RunnerHandle?
    private var readers: [PipeReader] = []
    private var continuation: AsyncStream<Input>.Continuation?
    /// The timers: the stop escalation and the drain wait.
    private var tasks: [Task<Void, Never>] = []
    private var stopRequested = false
    private var splitter = RunnerLineSplitter()
    private var stdoutEnded = false
    private var stderrEnded = false
    private var closedReaders = 0
    private var drainRearms = 0
    private var terminated: ContainerExit?
    /// Set when the output is over: the readers were told to stop, and the run is reported once they closed their descriptors.
    private var closing: ContainerExit?
    private var waiters: [CheckedContinuation<ContainerExit, Never>] = []

    init(
        executable: URL, arguments: [String],
        environment: [String: String] = ContainerRunnerArguments.minimalEnvironment(from: ProcessInfo.processInfo.environment),
        log: ContainerLog = ContainerLog(), clock: any Clock<Duration> = ContinuousClock(), timing: Timing = Timing(),
        registry: ContainerProcesses = .shared, backlog: OutputBacklog = OutputBacklog()
    ) {
        self.executable = executable
        self.arguments = arguments
        self.environment = environment
        self.log = log
        self.clock = clock
        self.timing = timing
        self.registry = registry
        self.backlog = backlog
    }

    isolated deinit {
        guard let handle, exit == nil else { return }
        handle.forceKill()
        backlog.close()
        for reader in readers { reader.cancel() }
        handle.closeStdin()
        registry.unregister(handle)
        continuation?.finish()
        for task in tasks { task.cancel() }
    }

    var isRunning: Bool { handle != nil && exit == nil }

    /// The descriptors this run holds open: none before the start and after the end.
    var openDescriptorCount: Int { ledger.count }  // @dw:accept:this referenced-only-by-tests -- a test reads it

    /// Starts the runner. Throws when the file is not an executable or the system refuses to start it; nothing stays open then.
    func start() throws {
        guard handle == nil, exit == nil else { throw ContainerProcessError(reason: "The container runner was already started.") }
        guard FileManager.default.isExecutableFile(atPath: executable.path) else {
            throw ContainerProcessError(reason: "The container runner is missing or not executable: \(executable.path)")
        }
        guard let pipes = RunnerPipes(ledger: ledger) else {
            throw ContainerProcessError(reason: "The container runner's pipes could not be opened.")
        }
        let process = Process()
        process.executableURL = executable
        process.arguments = arguments
        process.environment = environment
        pipes.connect(process)
        guard let handle = RunnerHandle(process: process, stdin: pipes.input, ledger: ledger) else {
            pipes.closeChildEnds()
            pipes.closeReadEnds()
            pipes.closeInput()
            throw ContainerProcessError(reason: "The container runner's input could not be prepared.")
        }
        let (stream, continuation) = AsyncStream.makeStream(of: Input.self)
        process.terminationHandler = { process in
            let signaled = process.terminationReason == .uncaughtSignal
            continuation.yield(.terminated(ContainerExit(status: process.terminationStatus, signaled: signaled)))
        }
        do {
            try process.run()
        } catch {
            pipes.closeChildEnds()
            pipes.closeReadEnds()
            handle.closeStdin()
            continuation.finish()
            throw ContainerProcessError(reason: "The container runner did not start: \(error.localizedDescription)")
        }
        // The child has its own copies of its ends; the parent's copies would keep the pipes open after the child is gone.
        pipes.closeChildEnds()
        readers = [
            follow(pipes.outputRead, into: continuation, data: Input.stdout, ended: .stdoutEnded),
            follow(pipes.errorRead, into: continuation, data: Input.stderr, ended: .stderrEnded),
        ]
        self.handle = handle
        self.continuation = continuation
        registry.register(handle)
        Task { [weak self] in
            for await input in stream {
                guard let self else { return }
                if self.apply(input) { return }
            }
        }
    }

    /// Asks the runner to stop and escalates when it does not: SIGTERM after the grace, SIGKILL after another. Does nothing
    /// when the run is not started, ended, or already asked to stop.
    func stop() {
        guard let handle, exit == nil, !stopRequested else { return }
        stopRequested = true
        handle.requestStop()
        tasks.append(
            Task { [clock, timing] in
                guard (try? await clock.sleep(for: timing.stopGrace)) != nil else { return }
                handle.terminate()
                guard (try? await clock.sleep(for: timing.terminateGrace)) != nil else { return }
                handle.forceKill()
            })
    }

    /// SIGKILL at once. Does nothing when the run is not started or ended.
    func kill() {
        guard exit == nil else { return }
        handle?.forceKill()
    }

    /// Returns the exit, waiting for the run to end when it has not. A process that was never started has no run to wait for: it
    /// returns ``ContainerExit/notStarted`` at once.
    func waitForExit() async -> ContainerExit {  // @dw:accept:this referenced-only-by-tests -- the machine start awaits the end with it
        if let exit { return exit }
        guard handle != nil else { return .notStarted }
        return await withCheckedContinuation { waiters.append($0) }
    }

    // MARK: - Following the process

    /// Follows the read end `descriptor`, which the reader owns from now on, and reports each piece, then its end, then the
    /// closing of the descriptor, in order.
    private nonisolated func follow(
        _ descriptor: Int32, into continuation: AsyncStream<Input>.Continuation, data: @escaping @Sendable ([UInt8]) -> Input,
        ended: Input
    ) -> PipeReader {
        PipeReader.follow(descriptor, backlog: backlog, ledger: ledger) { report in
            switch report {
            case .data(let bytes): continuation.yield(data(bytes))
            case .ended: continuation.yield(ended)
            case .closed: continuation.yield(.readerClosed)
            }
        }
    }

    /// Applies one report; true when the run is over and nothing more is read.
    private func apply(_ input: Input) -> Bool {
        defer { backlog.applied(input.byteCount) }
        if case .readerClosed = input { closedReaders += 1 }
        if let closing {
            // The output is over: what still arrives is dropped, and the run is reported when the last reader closed.
            return reportIfClosed(closing)
        }
        var drainExpired = false
        switch input {
        case .stdout(let bytes):
            for line in splitter.append(bytes) { applyLine(line) }
            log.noteDroppedLines(total: splitter.droppedLines)
        case .stderr(let bytes):
            log.appendDiagnostics(bytes)
        case .stdoutEnded:
            stdoutEnded = true
        case .stderrEnded:
            stderrEnded = true
        case .readerClosed:
            break
        case .terminated(let exit):
            terminated = exit
            if !(stdoutEnded && stderrEnded) { armDrainTimer() }
        case .drainExpired:
            guard !rearmDrainTimer() else { return false }
            drainExpired = true
        }
        guard let terminated, (stdoutEnded && stderrEnded) || drainExpired else { return false }
        beginClosing(with: terminated)
        return reportIfClosed(terminated)
    }

    private func applyLine(_ line: [UInt8]) {
        guard let event = ContainerEvent(line: line) else { return log.noteIgnoredLine() }
        log.apply(event)
        onEvent?(event)
    }

    /// Waits for the output to end, after the process did, for `Timing.drainGrace`.
    private func armDrainTimer() {
        tasks.append(
            Task { [clock, timing, continuation] in
                guard (try? await clock.sleep(for: timing.drainGrace)) != nil else { return }
                continuation?.yield(.drainExpired)
            })
    }

    /// True when the drain wait ran out while read output was still waiting to be applied: the application is behind, not the
    /// runner's descendants holding the pipe, so the wait starts again. It does so a few times at most.
    private func rearmDrainTimer() -> Bool {
        guard backlog.queuedBytes > 0, drainRearms < Self.maxDrainRearms else { return false }
        drainRearms += 1
        armDrainTimer()
        return true
    }

    /// Ends the reading: the last partial line, the timers, the input, the registry, and the readers, which close their
    /// descriptors on their own queues.
    private func beginClosing(with result: ContainerExit) {
        for line in splitter.finish() { applyLine(line) }
        log.noteDroppedLines(total: splitter.droppedLines)
        closing = result
        for task in tasks { task.cancel() }
        tasks = []
        if let handle {
            handle.closeStdin()
            registry.unregister(handle)
        }
        backlog.close()
        for reader in readers { reader.cancel() }
    }

    /// Reports the run once every reader has closed its descriptor; true when it did.
    private func reportIfClosed(_ result: ContainerExit) -> Bool {
        guard closedReaders == readers.count else { return false }
        continuation?.finish()
        continuation = nil
        exit = result
        onExit?(result)
        let waiting = waiters
        waiters = []
        for waiter in waiting { waiter.resume(returning: result) }
        return true
    }
}
```

```swift
        directory = try scratchDirectory()
        executable = directory.appending(path: "runner.sh")
        try Data("#!/bin/sh\n\(body)\n".utf8).write(to: executable)
        try FileManager.default.setAttributes([.posixPermissions: 0o700], ofItemAtPath: executable.path)

        try? FileManager.default.removeItem(at: directory)

    /// The pid the script wrote to its pid file, when it did.

/// Records `1` in `probe` when the process `pid` exits. (Not isolated: a handler made on the main actor would be asserted to run
/// there.)
private nonisolated func watchExit(of pid: Int32, into probe: AsyncEventProbe<Int>) -> any DispatchSourceProcess {
    let watcher = DispatchSource.makeProcessSource(identifier: pid, eventMask: .exit, queue: .global())
    watcher.setEventHandler { probe.record(1) }
    watcher.activate()
    return watcher
}

/// A pausable reader stand-in that counts how often it was paused and resumed.

    var resumed: Int { counts.withLock { $0.resumed } }
    func pause() { counts.withLock { $0.paused += 1 } }
    func resume() { counts.withLock { $0.resumed += 1 } }
```
