# D03 — F5: each pinned key carries its expiry; the verifier refuses an expired key; a test warns 90 days ahead

Model: haiku · Effort: low · Worktree: yes, `WT = ~/Developer/g-cqd/VMRunner-chains/d-security` (branch `chain/d-security`) · Chain: D, card 3 of 22 (after D02; next D04)

Anchors: locate every edit by its text (`grep -n`), never by a line number. Verified on `main` at `73bceb0`.

Why: ADR-0023 says the app cannot see a pinned key's expiry. The expiry is a fact of the vendor's key (its self-signature) and
can be pinned with the key. Read on 2026-10-22 from the vendors' key files: none of the four keys pinned today (Debian CD,
Ubuntu CD image 2012, Fedora 44, Alpine's signer) states an expiry, so each keeps `expires == nil`; Debian's archive key (D20,
held) expires 2035-03-28. Behaviour chosen at expiry: a signature is refused from the second the pinned key expires
(`now >= expires`), whatever the signature's own date, so an expired key fails closed until an app update pins its successor.
The test window is 90 days (owner may change it; see INDEX-D).

## Test

Append at the end of `Tests/VMRunnerTests/PGPVerificationTests.swift` (after the closing brace of `struct PGPPinnedKeyTests`):

```swift

struct PGPKeyExpiryTests {
    private let signer: TestSigner
    private let data = Array("SHA256SUMS of a synthetic release\n".utf8)

    init() throws { signer = try SharedSigner.get() }

    @Test func aPinnedKeyIsRefusedFromTheSecondItExpiresAndAcceptedBefore() throws {
        let now = UInt32(pgpTestNow.timeIntervalSince1970)
        let armored = try signer.detachedSignature(over: data)
        var pinned = signer.pinned
        pinned.expires = now + 1
        try PGP.Check.detached(armored, keys: [pinned.publicKey()], now: pgpTestNow).verify(data)
        pinned.expires = now
        #expect(throws: PGP.Failure.keyExpired) { try PGP.Check.detached(armored, keys: [pinned.publicKey()], now: pgpTestNow) }
    }

    @Test func theExpiryIsNotPartOfTheFingerprint() throws {
        var pinned = signer.pinned
        pinned.expires = 2_000_000_000
        #expect(try pinned.publicKey().fingerprint == signer.key.fingerprint)
    }

    /// Fails 90 days before a pinned key expires, so a release never ships a key that stops working soon after.
    @Test func noPinnedKeyExpiresWithinNinetyDays() {
        let horizon = Date().addingTimeInterval(90 * 86_400)
        for key in PGP.PinnedKeys.all {
            guard let expires = key.expires else { continue }
            #expect(Date(timeIntervalSince1970: TimeInterval(expires)) > horizon, "\(key.owner) expires within 90 days: pin its successor")
        }
    }
}
```
