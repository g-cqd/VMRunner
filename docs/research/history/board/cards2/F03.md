# F03 — Derived address blocks live 12 hours: the oldest goes first, and housekeeping prunes them

Model: haiku · Effort: low · Worktree: yes, `WT = ~/Developer/g-cqd/VMRunner-chains/f-followups` (branch `chain/f-followups`) · Chain: F, card 3 of 12 (after F02; next F04)

Anchors: locate every edit by its text (`grep -nF`), never by a line number. Verified on `main` at `a98fd14`.

Why (read from the code): `PolicyGate.remember` records a port-scoped block target in `derivedBlocks` (a `NameTable` of
capacity 1,024) with `ttl: .infinity`. When the table is full, `NameTable.evict` drops the address whose latest expiry is the
smallest; with every expiry infinite that is whichever the dictionary lists first, so eviction is arbitrary. And nothing
prunes the table: the stack's housekeeping (`UserNetCore.tick`, every 30 seconds) prunes only `gate.names`. After this card
an entry lives `PolicyGate.derivedBlockLifetime` (12 hours, refreshed each time the proxy gives the address again), so the
oldest goes first past 1,024 addresses, and the housekeeping prunes `derivedBlocks` with `names`. A rule therefore keeps
holding for an address for 12 hours after the proxy last gave it, no longer for the life of the stack.

```swift
    @Test func pastItsBoundTheDerivedBlockTableForgetsTheOldestAddressFirst() throws {
        var gate = PolicyGate(policy: try policy { $0.blockedConnections = [try ConnectionRule("evil.test:22")] })
        let first = ipv4("11.0.0.0")
        for index in 0...1_024 {  // 1,025 addresses, one a second, for a table of 1,024
            gate.remember(name: "evil.test", address: first + UInt32(index), ttl: 60, now: TimeInterval(index))
        }
        let now = TimeInterval(1_025)
        #expect(gate.derivedBlocks.count == 1_024)
        #expect(gate.derivedBlocks.names(for: first, now: now).isEmpty, "the oldest address went first")
        #expect(gate.derivedBlocks.names(for: first + 1, now: now) == ["evil.test"])
        #expect(gate.derivedBlocks.names(for: first + 1_024, now: now) == ["evil.test"])
    }

    @Test func theHousekeepingForgetsADerivedBlockOnceItsLifetimeIsOver() throws {
        let rig = CoreRig(policy: try policy { $0.blockedConnections = [try ConnectionRule("evil.test:22")] })
        _ = resolve(rig, "evil.test", addresses: ["6.6.6.6"])
        rig.advance(PolicyGate.derivedBlockLifetime + 60)  // past the lifetime and the next 30-second housekeeping
        _ = resolve(rig, "evil.test", addresses: ["6.6.6.7"])
        #expect(rig.core.gate.derivedBlocks.count == 1, "only the address given after the lifetime is left")
    }

```
