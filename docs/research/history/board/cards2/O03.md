Why, and where the filter goes (decided by reading the code): the same bytes reach two kinds of reader. The bridge
(`ConsoleBridge`, run by the helper) serves every client, and keeps a 64 KiB replay; `ConsoleSession` (exec, the agent path)
reads them through the bridge to find prompts (`PromptClassifier`) and the exec markers (`ExecScanner`), which need the raw
bytes (a marker split by a colour sequence, or a prompt after a title sequence, must still be seen exactly as the guest
sent it; `PromptClassifier.strippingEscapes` does its own reading). Only `ConsoleRelay`, the client that `vmr guest
console` runs, writes to a person's terminal. So the filter sits in `ConsoleRelay.run`, on the console-to-terminal
direction only, and nowhere in the bridge or the session. What the person types still goes to the guest unchanged.

This card: `ConsoleRelay.run` takes `filter: ConsoleOutputFilter?` (required, so no caller gets the raw path by default)
and `wake: Int32 = -1` (a descriptor whose readability ends the relay with a new `Ending.interrupted`; O04 connects it to
signals); `ConsoleRelay.closingBytes(filtered:)` gives what to write once a session ends (a colour reset after a filtered
session; after a raw one, also the modes a guest's programs most often leave on: O05 uses it). The `console` command moves
its body to a new `ConsoleAttach` in `Sources/DevTools/Guest` (next to `TerminalMode`, and so `GuestCommand` does not
grow), which passes a filter and writes the colour reset to the terminal when the session ends. `GuestCommand.swift` keeps
its `import GuestConsole`: the `exec` command still reads `result.output` and `result.status` of the console library's
result type, and `MemberImportVisibility` makes the build fail without the import. The help text says what is filtered.

```swift
import Foundation

/// Relays bytes between a person's terminal and a console socket until one side ends, the person detaches or the caller
/// wakes it. What the person types reaches the console unchanged; what the console prints passes through a
/// ``ConsoleOutputFilter`` first, unless the caller gives none.
public enum ConsoleRelay {
    /// Control-] (as in telnet): typed on the input, it ends the relay.
    public static let detachByte: UInt8 = 0x1D

    public enum Ending: Equatable, Sendable {
        /// The console closed.
        case consoleClosed
        /// The input ended.
        case inputEnded
        /// The person typed the detach byte.
        case detached
        /// The `wake` descriptor became readable (the caller's signal watch, for one).
        case interrupted
    }

    /// Connects to the console at `socketPath` and relays until it ends. A console that has a client answers with one line and
    /// closes, which shows up as `.consoleClosed` after that line was copied to `output`.
    public static func run(
        socketPath: String, input: Int32, output: Int32, filter: ConsoleOutputFilter?, wake: Int32 = -1
    ) throws -> Ending {
        let console = try ConsoleSocket.connect(to: socketPath)
        defer { ConsoleSocket.close(console) }
        return try run(console: console, input: input, output: output, filter: filter, wake: wake)
    }

    /// Relays `input` to the connected socket `console`, and the console's output to `output` through `filter` when there is
    /// one. When `wake` (never polled when negative) becomes readable the relay ends with `.interrupted`. The caller puts a
    /// terminal into raw mode first, when there is one; this does not touch terminal settings.
    public static func run(
        console: Int32, input: Int32, output: Int32, filter: ConsoleOutputFilter?, wake: Int32 = -1
    ) throws -> Ending {
        var filter = filter
        var buffer = [UInt8](repeating: 0, count: 16 * 1024)
        while true {
            var entries = [
                pollfd(fd: console, events: Int16(POLLIN), revents: 0), pollfd(fd: input, events: Int16(POLLIN), revents: 0),
                pollfd(fd: wake, events: Int16(POLLIN), revents: 0),
            ]
            // Three entries, three descriptors; poll skips a negative one.
            let ready = unsafe poll(&entries, 3, -1)
            if ready < 0 {
                if errno == EINTR { continue }
                throw ConsoleError.system(call: "poll", code: errno)
            }
            // Drain the console first, so output that arrived before a detach or the end of the input is not lost.
            if entries[0].revents != 0 {
                switch ConsoleSocket.read(console, into: &buffer) {
                case .transferred(let count):
                    let shown = filter?.pass(buffer[0..<count]) ?? Array(buffer[0..<count])
                    if !shown.isEmpty { try ConsoleSocket.writeAll(output, shown, stallMilliseconds: 10_000) }
                case .wouldBlock: break
                case .endOfStream, .failed: return .consoleClosed
                }
            }
            if entries[1].revents != 0 {
                switch ConsoleSocket.read(input, into: &buffer) {
                case .transferred(let count):
                    let typed = Array(buffer[0..<count])
                    let detach = typed.firstIndex(of: detachByte)
                    try ConsoleSocket.writeAll(console, Array(typed[0..<(detach ?? typed.count)]), stallMilliseconds: 10_000)
                    if detach != nil { return .detached }
                case .wouldBlock: break
                case .endOfStream, .failed: return .inputEnded
                }
            }
            if entries[2].revents != 0 { return .interrupted }
        }
    }

    /// What to write to the person's terminal once the relay has ended. Filtered output can only have left colours and
    /// attributes set, so resetting those is enough. Raw output may have set anything, so the modes a guest's programs most
    /// often leave on are turned off too: the alternate screen, mouse and focus reports, bracketed paste, application cursor
    /// keys and keypad, a keyboard protocol, a hidden cursor, autowrap off, a scroll region (reset between saving and
    /// restoring the cursor, as the reset moves it) and a line-drawing character set.
    public static func closingBytes(filtered: Bool) -> [UInt8] {
        let attributes = "\u{1B}[0m"
        guard !filtered else { return Array(attributes.utf8) }
        let modes = [
            "?1049l", "?1000l", "?1002l", "?1003l", "?1005l", "?1006l", "?1015l", "?1004l", "?2004l", "?1l", "=0;1u", "?25h", "?7h",
        ]
        let others = "\u{1B}>" + "\u{1B}7\u{1B}[r\u{1B}8" + "\u{1B}(B\u{0F}"
        return Array((modes.map { "\u{1B}[" + $0 }.joined() + others + attributes).utf8)
    }
}

import Foundation
import GuestConsole

/// `vmr guest console`: this terminal attached to a guest's console. What the guest prints passes through a
/// ``ConsoleOutputFilter`` before it reaches the terminal, and the colours it may have left set are reset at the end.
enum ConsoleAttach {
    static func run(socket: String) throws -> Int32 {
        Output.err("attached to \(socket); Ctrl-] detaches")
        let ending: ConsoleRelay.Ending
        do {
            ending = try TerminalMode.raw {
                try ConsoleRelay.run(socketPath: socket, input: STDIN_FILENO, output: STDOUT_FILENO, filter: ConsoleOutputFilter())
            }
        } catch let error as ConsoleError {
            resetScreen()
            throw GuestExec.failure(error)
        }
        resetScreen()
        switch ending {
        case .consoleClosed: Output.err("\nthe console closed")
        case .inputEnded: Output.err("\nend of input")
        case .detached: Output.err("\ndetached")
        case .interrupted: Output.err("\ninterrupted")
        }
        return 0
    }

    /// Resets what the guest's output may have left set on the terminal; nothing when standard output is not a terminal.
    private static func resetScreen() {
        guard isatty(STDOUT_FILENO) == 1 else { return }
        try? FileHandle.standardOutput.write(contentsOf: Data(ConsoleRelay.closingBytes(filtered: true)))
    }
}
```

import Foundation
import Testing

@testable import GuestConsole

/// The relay on socket pairs: what reaches the person's terminal with and without the filter, a sequence cut by the relay's
/// own reads, the wake descriptor, and what is written once a session ends.
struct ConsoleRelayTests {
    private struct Session {
        let shown: [UInt8]
        let ending: ConsoleRelay.Ending
    }

    /// The console sends `guestOutput` and closes; the input sends nothing. Returns what reached the terminal's side.
    private func relay(_ guestOutput: [UInt8], filter: ConsoleOutputFilter?) throws -> Session {
        let console = try #require(ConsoleSocket.streamPair(bufferBytes: 256 * 1024))
        let terminal = try #require(ConsoleSocket.streamPair(bufferBytes: 256 * 1024))
        var input: [Int32] = [-1, -1]
        try #require(unsafe pipe(&input) == 0)
        defer {
            for descriptor in input + [console.first, terminal.second] { ConsoleSocket.close(descriptor) }
        }
        // The relay writes to a peer that reads only afterwards: non-blocking, so a regression fails instead of hanging.
        _ = fcntl(terminal.first, F_SETFL, O_NONBLOCK)
        let guest = GuestEnd(descriptor: console.second)
        guest.send(guestOutput)
        guest.close()
        let ending: ConsoleRelay.Ending
        do {
            ending = try ConsoleRelay.run(console: console.first, input: input[0], output: terminal.first, filter: filter)
        } catch {
            ConsoleSocket.close(terminal.first)
            throw error
        }
        ConsoleSocket.close(terminal.first)
        return Session(shown: GuestEnd(descriptor: terminal.second).receive(count: Int.max), ending: ending)
    }

    @Test(.timeLimit(.minutes(1)))
    func theFilterTakesTheGuestsSequencesOutAndKeepsItsText() throws {
        let hostile = "login: \u{1B}]52;c;b3duZWQ=\u{07}\u{1B}[?1049h\u{1B}[6n\u{1B}[1;32mok\u{1B}[0m\r\n"
        let session = try relay(Array(hostile.utf8), filter: ConsoleOutputFilter())
        #expect(session.shown == Array("login: \u{1B}[1;32mok\u{1B}[0m\r\n".utf8))
        #expect(session.ending == .consoleClosed)
    }

    @Test(.timeLimit(.minutes(1)))
    func withoutAFilterEveryByteGoesThroughUnchanged() throws {
        let bytes = Array("\u{1B}]0;title\u{07}\u{1B}[?2004htext".utf8) + [0x9B, 0xFF]
        let session = try relay(bytes, filter: nil)
        #expect(session.shown == bytes)
        #expect(session.ending == .consoleClosed)
    }

    @Test(.timeLimit(.minutes(1)))
    func aSequenceCutByTheRelaysOwnReadsIsStillRemovedWhole() throws {
        // The relay reads at most 16 KiB at a time; the clipboard sequence starts 4 bytes before that boundary.
        let text = [UInt8](repeating: UInt8(ascii: "x"), count: 16 * 1024 - 4)
        let session = try relay(text + Array("\u{1B}]52;c;b3duZWQ=\u{07}done".utf8), filter: ConsoleOutputFilter())
        #expect(session.shown == text + Array("done".utf8))
    }

    @Test(.timeLimit(.minutes(1)))
    func aReadableWakeDescriptorEndsTheRelay() throws {
        let console = try #require(ConsoleSocket.streamPair(bufferBytes: 64 * 1024))
        var input: [Int32] = [-1, -1]
        var wake: [Int32] = [-1, -1]
        var sink: [Int32] = [-1, -1]
        try #require(unsafe pipe(&input) == 0)
        try #require(unsafe pipe(&wake) == 0)
        try #require(unsafe pipe(&sink) == 0)
        defer {
            for descriptor in input + wake + sink + [console.first, console.second] { ConsoleSocket.close(descriptor) }
        }
        var byte: UInt8 = 15
        #expect(unsafe Darwin.write(wake[1], &byte, 1) == 1)
        let ending = try ConsoleRelay.run(
            console: console.first, input: input[0], output: sink[1], filter: ConsoleOutputFilter(), wake: wake[0])
        #expect(ending == .interrupted)
    }

    @Test
    func theResetAfterARawSessionIsMadeOfWhatTheFilterNeverLetsThroughAndAColourReset() {
        var filter = ConsoleOutputFilter()
        let afterRaw = ConsoleRelay.closingBytes(filtered: false)
        #expect(ConsoleRelay.closingBytes(filtered: true) == Array("\u{1B}[0m".utf8))
        #expect(filter.pass(afterRaw[...]) == ConsoleRelay.closingBytes(filtered: true))
        #expect(afterRaw.count > 60)
    }
}

## Test

Through the relay on socket pairs: a hostile guest output (clipboard write, alternate screen, a cursor position query
between a login prompt and coloured text) reaches the terminal side as the prompt and the coloured text only, and the relay
ends with `.consoleClosed`; without a filter every byte, the invalid ones included, goes through unchanged; a clipboard
sequence that starts 4 bytes before the relay's 16 KiB read boundary is still removed whole; a readable wake descriptor ends
the relay with `.interrupted`; the bytes written after a raw session, passed through the filter, leave only the colour reset
(so the reset turns off only what filtered output could never have turned on, plus colours). The existing end-to-end relay
test (detach key, raw copy) still passes. The writing end the tests do not read during the relay is non-blocking.
