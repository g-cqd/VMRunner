# D09 — F6: a port rule for a name keeps holding after the name table forgets the answer (derived address blocks)

Model: haiku · Effort: low · Worktree: yes, `WT = ~/Developer/g-cqd/VMRunner-chains/d-security` (branch `chain/d-security`) · Chain: D, card 9 of 22 (after D08; next D10)

Anchors: locate every edit by its text (`grep -n`), never by a line number. Verified on `main` at `73bceb0`.

Why (read from the code): a block rule that names a domain on every port (`evil.test`) refuses the name before it is resolved
(`PolicyGate.nameBlock`), so it never depends on the name table. A block rule that names a domain on some ports
(`evil.test:22`) does not stop resolution, so the guest gets the address, and the rule is applied per connection through the
name table (`PolicyGate.judge` evaluates every name the table holds for the address). The table forgets the name after the
record's TTL (30 seconds to an hour), and from then on a connection to that address on port 22 is judged by the address alone
and allowed. Fix: when the DNS proxy hands out an address for a name that such a port-scoped rule targets, the gate also keeps
that pair in a second, bounded table that does not expire (`derivedBlocks`, 1,024 addresses), and `judge` consults it for
blocks only, so it can never allow anything. The guest's reach only shrinks: no exposure line changes.

    /// Remembers that the DNS proxy gave the guest `address` for `name`: for `ttl` seconds in ``names``, and for as long as the
    /// gate lives in ``derivedBlocks`` when a block rule with ports names `name`.
    package mutating func remember(name: String, address: UInt32, ttl: TimeInterval, now: TimeInterval) {

    /// Whether a block rule that names `name` applies to some ports only. A rule for every port refuses the name before it is
    /// resolved (``nameBlock(for:)``); these are the rules that are applied per connection and need ``derivedBlocks``.
    private func isPortScopedBlockTarget(_ name: String) -> Bool {
        guard let form = try? HostForm(parsing: name), case .name(let normalized) = form else { return false }
        return policy.blockedConnections.contains { rule in
            guard !rule.ports.isEmpty, case .name(let domain) = rule.target else { return false }
            return domain.matches(normalized)
        }
    }
