- **Model:** haiku, low. **Worktree:** yes (E). **Size:** about 75 lines.
- **Design:** `.managedLock(key)` disables a control whose setting the organisation restricted and puts a lock beside it with
  a tooltip, in the same `HStack` shape as `.settingHelp`. It goes **before** `.settingHelp`, so the help button stays usable.
  A key is locked only where it restricts: `Allow…` forced to anything but true, `RequireDisposableMachines` forced to
  anything but false, `MaxRuntimeMinutes` forced at all (the whole stepper locks). The policy is read when the view is drawn
  (`ManagedPreferences.current`); the library's clamp (E14) is what enforces it.

  2. Create `Sources/VMRunner/Views/ManagedLock.swift`:
     ```swift
     import SwiftUI

     extension View {
         /// Disables the control when the organisation restricted `key`, and shows a lock that says so. Put it before
         /// `.settingHelp`, so the help button stays usable.
         func managedLock(_ key: ManagedKey, in policy: ManagedPreferences = .current) -> some View {
             lockedByOrganisation(policy.isLocked(key))
         }

         private func lockedByOrganisation(_ isLocked: Bool) -> some View {
             HStack(alignment: .firstTextBaseline) {
                 self.disabled(isLocked)
                 if isLocked {
                     Image(systemName: "lock.fill")
                         .foregroundStyle(.secondary)
                         .help(ManagedPreferences.lockedHelp)
                         .accessibilityLabel(ManagedPreferences.lockedHelp)
                 }
             }
         }
     }
     ```
