- **Why:** the app's own settings are read and written under string keys spelled out in `SettingsView`, `VMRunnerApp`,
  `ContentView`, `Provisioner`, `LatencyActivity` and `NewMachineModel`. Managed preferences (E14 to E16) must name the same
  keys to lock them, so the keys become one enum. The raw values are exactly the strings stored today, so no stored setting
  is lost; a test pins them.

     ```swift
     /// The keys of the app's own settings, in the domain `PreferencesDomain.defaults` names. The raw values are what every
     /// version so far has stored, so they never change.
     enum AppSetting: String, CaseIterable, Sendable {
         case hidesToolbarInFullScreen, keepsRestoreImages, holdsLatencyActivity, ipswDeviceIdentifier
     }
     ```

     ```swift
         @AppStorage("ipswDeviceIdentifier", store: PreferencesDomain.defaults) private var storedDevice = ""
     ```
