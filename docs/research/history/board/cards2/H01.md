Model: haiku · Effort: low · Worktree: yes, `WT = ~/Developer/g-cqd/VMRunner-chains/h-macos` (branch `chain/h-macos`, created from `main` at `471c681`) · Chain: H

Why (authorised real-guest run, 2026-10-22): a macOS 26.6.2 install into a 16 GiB disk (the sheet's minimum, `EditorLimits.newDiskGiB = 16...2048`, one range for both guests) failed after the 18.4 GiB download with a bare `VZErrorDomain 10007` and the window said only "Installation failed". The same install into a 40 GiB sparse disk worked in about 4 minutes and used 21 GB. A value between 16 and 40 was not tried.

## Change
1. `EditorLimits`: replace `static let newDiskGiB = 16...2048` by `static let newLinuxDiskGiB = 16...2048` and `static let newMacDiskGiB = 40...2048`, with a doc comment on the second: "The smallest disk a macOS install was seen to succeed on (a real run); 16 GiB failed. Not probed in between." Add `static func newDiskGiB(for guest: GuestOS) -> ClosedRange<Int>`.
2. `NewMachineSheet`: the `Stepper` uses `EditorLimits.newDiskGiB(for: <the sheet's guest>)`; `ResourcesSection` gets the guest as a `let guest: GuestOS` parameter, passed from `model.config.guest`.
3. `NewMachineModel.guestChanged(to:)`: after its existing work, clamp `config.diskGiB` into the new guest's range (`min(max(...))`). Read the function first; keep what it does today (name, defaults).
4. `.diskSize` help paragraph: one sentence "A new macOS machine needs at least 40 GiB: an install into 16 GiB failed." (the disk is sparse, so the space is used only as the guest writes). Keep the summary ≤110 chars and ending with "."; `HelpTests` guards it.
5. Tests: (a) the range for `.macOS` starts at 40 and for `.linux` at 16; (b) `guestChanged(to: .macOS)` on a model whose `config.diskGiB` is 16 raises it to 40; switching back to Linux keeps 40; (c) a default `VMConfig.new(guest: .macOS)` (100 GiB) is inside the macOS range.
6. Roadmap 0030: add the line "2026-10-22: a macOS install into a 16 GiB disk failed (`VZErrorDomain 10007`), into 40 GiB it worked; the new-machine minimum for macOS is 40 GiB." under the checklist item for macOS, and nothing else.
