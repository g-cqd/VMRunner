# Diary — 2026-10-21 (1)

## The runner and its first hardening

The core app: machine model, storage, APFS cloning, hardened downloads, the builder from settings to a VM configuration,
the controller, provisioning, view models, help, the interface. Decisions: ADR-0002, ADR-0003, ADR-0004, ADR-0015.

| # | Claim | Probe | Verdict |
|---|---|---|---|
| 1 | A saved state restores only into an identical device configuration | Restore failed with "invalid argument"; pinned the NAT MAC and the starting display size | CONFIRMED (restore works after the pin) |
| 2 | A cached installer can be stale | A cached `mini.iso` was reused after the mirror changed; re-verified against the checksum before reuse | CONFIRMED |
| 3 | Profiles may switch on Secure Boot on any host | Enabled it on a macOS 26.7 host | REFUTED — the API exists only on macOS 27; gated by host capability |
| 4 | The framework supports two displays | Configured two | REFUTED — one scanout per graphics device |
| 5 | "No 3D for any guest" | Re-read the framework's graphics options | REFUTED — macOS guests get Metal; Linux guests have none |
| 6 | The Help window opens on the topic you asked for | Selected a topic from a button | REFUTED — an optional tag broke the selection; fixed with a plain tag |

### What went wrong

A script that rewrote a view file replaced the empty string and corrupted the file; it was recovered by selecting every
second element and the edits were re-applied with asserted replacements. After that, scripted edits assert that the text
they replace exists.

### Not verified

Secure Boot on a macOS 27 host. Every guest feature combination on real hardware beyond the ones used during development.
