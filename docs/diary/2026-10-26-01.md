## Windows helper comparison

The first start with PMU enabled crashed Apple's helper within a second on 26A434. A fresh same-commit scratch comparison with PMU disabled remained running for 191 seconds and was deliberately stopped. Helper CPU stayed near one core and the disk had no sampled writes. Windows boot progress was not established. The [crash study](../research/windows-pmu-crash-2026-10.md) records the authorisation, configuration, evidence, limitations and comparison.

This points to rejecting the unsafe private capability before helper creation on the observed build. That containment is separate from this history import and does not claim to fix Apple's implementation or make Windows boot.
